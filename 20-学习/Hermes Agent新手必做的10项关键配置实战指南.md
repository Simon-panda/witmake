# Hermes Agent新手必做的10项关键配置实战指南

## ① 前置安装
**安装准备：** Mac/Linux/WSL2 直接安装，Windows 需先配置 WSL2。
- 执行 `hermes setup` 完成初始化
- 密钥异常时修改环境文件

## ② 基础配置三件套
**核心组合：**
- **Camofox** — 实现网页读取与表单填写
- **SOUL.md** — 沉淀用户偏好
- **副驾模型** — 分工处理杂务，降低主模型负载

## ③ 进阶能力配置
**记忆与搜索：**
- 微调记忆系统，避免重复提问
- 配置 `web_search` 接入实时信息源

## ④ 安全效率加固
**双重保障：**
- 自动化审计记录终端操作
- Docker 沙箱隔离高风险任务，保护宿主机

## ⑤ 高阶功能落地
**能力跃升：**
- 多 Agent 协同，并行处理任务
- 三层备份防数据丢失
- 常用 Skill 沉淀高频流程

---

## 未来行动指南

1. 按顺序完成 10 项配置，优先处理前置安装与基础三件套
2. 配置记忆系统时明确会话保存规则，设置 `web_search` 接入 Exa 服务
3. 启用自动化审计记录所有终端命令，创建专用 Docker Profile 隔离环境
4. 搭建多 Agent 节点处理复杂任务，实施本地-异地-远程三级备份
5. 将重复操作封装为 Skill，逐步构建个人化 Agent 工作流
