### 61. Rust

**前世今生**

Rust 由 Mozilla 研究院的 Graydon Hoare 于 2006 年发起，2010 年 Mozilla 正式接手开发，2015 年发布 1.0 稳定版。其设计目标是在不牺牲性能的前提下提供内存安全——通过所有权（ownership）、借用（borrowing）和生命周期（lifetime）三大机制，在编译期消灭空指针解引用、数据竞争和悬垂指针等内存错误，无需垃圾回收器。Rust 的诞生源于对 C/C++ 在并发编程中安全隐患的反思，吸收了 ML 系语言的代数数据类型、模式匹配和 trait 系统。2021 年 Rust 基金会成立，AWS、Google、Meta、微软等巨头成为创始成员。如今 Rust 已连续多年蝉联 Stack Overflow "最受喜爱语言"，并被 Linux 内核正式接纳为第二官方语言，在系统编程、WebAssembly、区块链和 CLI 工具领域占据重要地位。


**案例一：高性能 CLI 工具——文件搜索**
```rust
use std::fs;
use std::path::Path;

fn search(dir: &Path, pattern: &str) -> std::io::Result<()> {
    if dir.is_dir() {
        for entry in fs::read_dir(dir)? {
            search(&entry?.path(), pattern)?;
        }
    } else if let Some(name) = dir.file_name() {
        if name.to_string_lossy().contains(pattern) {
            println!("{}", dir.display());
        }
    }
    Ok(())
}
```

### 62. Go

**前世今生**

Go 语言（Golang）由 Google 的 Robert Griesemer、Rob Thompson 和 Ken Thompson 于 2007 年设计，2009 年开源发布，2012 年发布 1.0 稳定版。三位设计者中的 Ken Thompson 是 Unix 和 C 语言的共同创造者，这赋予了 Go 简洁务实的设计哲学。Go 的诞生源于对 C++ 编译速度和并发编程复杂性的不满——Google 需要一种既能快速编译、又能轻松编写并发程序的系统语言。Go 引入 goroutine 和 channel，将 CSP（通信顺序进程）模型带入主流。凭借极简语法（仅 25 个关键字）、内置并发支持和静态编译为单一二进制文件的能力，Go 迅速成为云原生基础设施的事实标准语言。Docker、Kubernetes、Prometheus、Terraform 等几乎所有关键云原生项目均使用 Go 编写，巩固了其"云计算语言"的地位。

**案例一：并发下载器**
```go
package main

import (
    "fmt"
    "io"
    "net/http"
    "os"
    "sync"
)

func download(url, filename string, wg *sync.WaitGroup) {
    defer wg.Done()
    resp, _ := http.Get(url)
    defer resp.Body.Close()
    f, _ := os.Create(filename)
    defer f.Close()
    io.Copy(f, resp.Body)
    fmt.Printf("Downloaded: %s\n", filename)
}

func main() {
    urls := map[string]string{
        "https://example.com/a.jpg": "a.jpg",
        "https://example.com/b.jpg": "b.jpg",
    }
    var wg sync.WaitGroup
    for url, file := range urls {
        wg.Add(1)
        go download(url, file, &wg)
    }
    wg.Wait()
}
```

**案例三：Channel 实现生产者-消费者模式**
```go
func producer(ch chan<- int) {
    for i := 0; i < 5; i++ {
        ch <- i
    }
    close(ch)
}

func consumer(ch <-chan int, done chan<- bool) {
    for v := range ch {
        fmt.Println("Consumed:", v)
    }
    done <- true
}

func main() {
    ch := make(chan int, 2)
    done := make(chan bool)
    go producer(ch)
    go consumer(ch, done)
    <-done
}
```

**进阶技巧：** 使用 `goimports` 自动管理导入；`pprof` 进行性能分析；`errgroup` 简化并发错误处理。避免过早使用 `reflect` 和 `unsafe` 包。Goroutine 泄漏是常见陷阱——确保每个 goroutine 有退出路径，常用 `context.Context` 控制生命周期。

### 63. Python

### 64. TypeScript

**前世今生**

TypeScript 由微软的 Anders Hejlsberg（C# 和 Turbo Pascal 之父）主导设计，2012 年 10 月首次公开发布，2014 年发布 1.0 正式版。TypeScript 是 JavaScript 的严格超集，为其添加了静态类型系统、接口、泛型和枚举等现代语言特性，同时完全兼容现有 JS 代码。其诞生源于大型前端项目（如 Bing、Office 365）对 JavaScript 可维护性的迫切需求——纯 JS 在百万行级别项目中极难重构和调试。TypeScript 编译器将 TS 代码编译为干净的 JS，类型信息在运行时被完全擦除。如今 TypeScript 已成为前端开发的绝对主流，Angular、Deno 等框架直接使用它，Vue 和 React 生态也以 TS 为首选。GitHub 的 Octoverse 报告显示，TypeScript 在过去 5 年一直是增长最快的语言之一。

**使用方法与案例**

**核心命令：**


**案例二：泛型工具函数**
```typescript
// 类型安全的 pick 函数
function pick<T, K extends keyof T>(obj: T, keys: K[]): Pick<T, K> {
  return keys.reduce((acc, key) => {
    acc[key] = obj[key];
    return acc;
  }, {} as Pick<T, K>);
}

const user = { id: 1, name: "Alice", email: "a@b.com" };
const picked = pick(user, ["id", "name"]); // { id: number; name: string }
```

### 65. Zig

**前世今生**

Zig 由 Andrew Kelley 于 2015 年创立，2016 年在 GitHub 上开源，目前仍在积极开发中（尚未发布 1.0）。Kelley 曾在多家公司担任 C/C++ 开发者，对现代 C 开发中的痛点——未定义行为、宏系统混乱、构建系统碎片化——有切肤之痛。Zig 的设计目标是成为"更好的 C"：提供可选的编译时求值、无隐式分配、无宏（用 `comptime` 替代）、无隐式类型转换、无预处理器。它最大的创新之一是与 C ABI 的直接兼容和内置的 C 交叉编译工具链——Zig 可以作为 C/C++ 项目的构建系统（`zig cc`），在不安装额外工具链的情况下交叉编译到任何目标平台。Zig 在系统编程、游戏引擎和嵌入式领域获得越来越多关注，TigerBeetle 金融数据库和 Bun JavaScript 运行时均使用 Zig 编写。

**使用方法与案例**

**安装：**
```bash
# macOS
brew install zig

# Linux (使用 zigup 管理版本)
curl -L https://github.com/marler8997/zigup/releases/latest/download/zigup-x86_64-linux.tar.gz
# 或直接下载二进制: https://ziglang.org/download/

# Windows
winget install -e --id zig.zig
```

**核心命令：**
```bash
zig init-exe               # 创建可执行项目
zig build run              # 构建并运行
zig test src/main.zig      # 运行测试
zig cc -o hello hello.c    # 作为 C 编译器
```

**案例一：内存安全的链表实现**
```zig
const std = @import("std");

pub fn main() !void {
    var gpa = std.heap.GeneralPurposeAllocator(.{}){};
    defer _ = gpa.deinit();
    const allocator = gpa.allocator();

    var list = std.ArrayList(i32).init(allocator);
    defer list.deinit();

    try list.append(1);
    try list.append(2);
    try list.append(3);

    for (list.items) |item| {
        std.debug.print("{d}\n", .{item});
    }
}
```

**案例二：编译时 JSON 解析**
```zig
const std = @import("std");

const User = struct {
    id: u32,
    name: []const u8,
};

// comptime 在编译期执行
pub fn main() void {
    const user = comptime blk: {
        var u = User{ .id = 1, .name = "Alice" };
        break :blk u;
    };
    std.debug.print("User: {s} (id={d})\n", .{user.name, user.id});
}
```

**案例三：作为 C 交叉编译器**
```bash

# 编译到 Windows
zig cc -target x86_64-windows-gnu -o hello.exe hello.c
```

**进阶技巧：** `defer` 和 `errdefer` 确保资源释放，是 Zig 的错误处理核心模式。`comptime` 可替代宏——在编译期生成代码、验证类型、计算常量。使用 `zig build-exe` 配合 `-fstrip` 生成极小的二进制文件。Zig 的 `@import("builtin")` 可获取目标平台信息实现条件编译。善用 `std.testing` 模块编写内联测试。

### 66. Bun

**前世今生**

Bun 由 Jarred Sumner 于 2021 年创建，2022 年 7 月发布第一个公开测试版，2023 年 9 月发布 1.0 稳定版，获得 Oven 公司 700 万美元种子轮融资。Sumner 此前在 Facebook 负责前端性能优化，他在开发中深感 Node.js 启动慢、模块解析复杂、工具链碎片化的痛苦。Bun 的目标是用一个单一工具取代 Node.js 运行时、npm 包管理器、打包器（Webpack/esbuild）和测试运行器（Jest）。它使用 Zig 语言编写核心（获得极致性能），内置 JavaScriptCore 引擎（WebKit 的 JS 引擎，比 V8 启动更快），原生支持 TypeScript 和 JSX 无需配置。Bun 的 npm 安装速度据称比 npm 快 25-30 倍。它正在迅速发展，虽然生态成熟度尚不及 Node.js，但已成为前端开发极具吸引力的替代方案。

**使用方法与案例**

**安装：**
```bash
# macOS/Linux
curl -fsSL https://bun.sh/install | bash

# Windows (需要 WSL)
# 通过 npm
npm install -g bun
```

**核心命令：**
```bash
bun init                # 初始化项目
bun run index.ts        # 运行 TS 文件（无需配置）
bun install             # 安装依赖（比 npm 快 25x）
bun test                # 运行测试
bun build ./src --outdir ./dist  # 打包
```

**案例一：快速 HTTP 服务器**

**案例二：文件操作 + SQLite 集成**
```typescript
import { Database } from "bun:sqlite";

const db = new Database("my.db");
db.run("CREATE TABLE IF NOT EXISTS logs (ts TEXT, msg TEXT)");
db.run("INSERT INTO logs VALUES (?, ?)", [new Date().toISOString(), "app started"]);

// 读取文件内容
const content = await Bun.file("data.txt").text();
const lines = content.split("\n").filter(Boolean);

// 批量写入
const insert = db.prepare("INSERT INTO logs VALUES (?, ?)");
db.transaction(() => {
  for (const line of lines) {
    insert.run(new Date().toISOString(), line);
  }
})();

const rows = db.query("SELECT * FROM logs").all();
console.table(rows);
```

### 67. Deno

**前世今生**

Deno 由 Node.js 创始人 Ryan Dahl 于 2018 年在 JSConf EU 上首次公布，2020 年 5 月发布 1.0 版本。Dahl 在 2017 年发表著名演讲《关于 Node.js 我后悔的 10 件事》，其中包括未采用 Promise、安全性不足、node_modules 黑洞、`package.json` 过度膨胀等。Deno 正是他对这些遗憾的系统性修正——默认安全（需显式授权文件/网络/环境访问）、原生 TypeScript 支持、去中心化模块系统（通过 URL 导入而非 npm）、内置工具链（格式化、检查、测试、文档生成）。2022 年 Deno 在 1.28 版本中宣布兼容 npm 包，标志着战略转向——承认 npm 生态的重要性。Deno 使用 Rust 编写核心（而非 C++），内置 V8 引擎。它正从"Node.js 替代品"重新定位为"现代 JavaScript/TypeScript 瑞士军刀"。

**使用方法与案例**

**安装：**
```bash

# 通过包管理器
```

**核心命令：**

### 69. Lua

**前世今生**

### 70. WASM (WebAssembly)

**前世今生**

WebAssembly（简称 WASM）由 W3C WebAssembly 社区组于 2015 年发起，2017 年发布 MVP（最小可行产品）版本，2019 年成为 W3C 正式推荐标准。它起源于 Mozilla 的 asm.js（2013 年）和 Google 的 Native Client（2011 年）两种尝试在浏览器中运行高性能代码的技术。WASM 定义了一种可移植的二进制指令格式，作为编译目标——C/C++、Rust、Go 等语言都可以编译为 WASM，在浏览器中以接近原生的速度运行。WASM 最初聚焦浏览器，但 2019 年 WASI（WebAssembly System Interface）标准的推出将其推向服务端。2021 年字节码联盟（Bytecode Alliance）成立，推动 WASM 成为"通用轻量容器"——比 Docker 容器更轻量、更安全、启动更快。如今 WASM 已从浏览器沙盒扩展到边缘计算（Cloudflare Workers）、插件系统（Figma、Photoshop Web 版）和区块链智能合约（Polkadot、CosmWasm）。
