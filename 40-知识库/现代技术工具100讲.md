## 第 1 组：文本搜索与处理 (Text Search & Processing)

### 1. ripgrep (rg)
Rust 编写的高性能文本搜索。多线程 + SIMD + 自动 skip .gitignore。对标 grep，快 10-100×。

### 2. fd
Rust 版 `find`。默认忽略 .gitignore，正则搜索文件名，彩色输出。`fd 'pattern'` 比 `find . -name` 快 5-10×。

### 3. fzf
Go 写的模糊搜索器。支持交互式过滤，管道友好。`Ctrl+T` 搜文件、`Ctrl+R` 搜历史、`**` 触发补全。

### 4. bat
Rust 版 `cat`，带语法高亮、行号、Git 变更标记。自动分页，可做 `bat --language=json file`。

### 5. delta
Rust 版 `diff`。Git diff 的语法高亮增强器，支持 side-by-side、行号、行内差异高亮。

### 6. jq
C 写的命令行 JSON 处理器。`curl api | jq '.data[0].name'` 是 API 调试标配。支持过滤、映射、聚合。

### 7. yq
Go 写的 YAML/JSON/XML/CSV 处理器。基于 jq 语法。`yq eval '.services.api.image' docker-compose.yaml`。

### 8. sd
Rust 版 `sed`，但语法直觉化。`sd 'before' 'after' *.rs` 替换，支持正则。比 sed 易用 10×。

### 9. choose
Rust 版 `cut`，但列可中文/按名选取。`ls -l | choose 4:8` 取第 4-8 列，比 awk 简洁。

### 10. xsv
Rust 写的高性能 CSV 工具包。`xsv search`、`xsv sort`、`xsv stats`、`xsv join`，百万行 CSV 秒级处理。

## 第 2 组：Shell 与终端 (Shell & Terminal)

### 11. zsh
Bash 的超集。自动补全更强、插件生态丰富（oh-my-zsh）、主题系统完善。macOS 默认 Shell。

### 12. fish
"开箱即用"的现代 Shell。语法高亮、自动建议、Web 配置界面。无需插件就有 IDE 级体验。

### 13. starship
Rust 写的跨 Shell 提示符。`~/project (main ✗)` 这种风格，支持 Git、Node、Python 等多语言状态。

### 14. tmux
终端复用器。一个 SSH 连接开多个窗口/面板，断开后 session 不丢。远程开发标配。

### 15. alacritty
Rust + GPU 加速的终端模拟器。最小延迟，支持 vi 模式、多窗口。追求极致性能。

### 16. kitty
Python/C 混合的 GPU 终端。原生分屏、图片显示、SSH 复用、ligature 支持。功能最全的现代终端。

### 17. warp
Rust 写的 AI 终端。IDE 式编辑、智能补全、Agent 模式。闭源，目前仅 macOS/Linux。

### 18. zellij
Rust 写的终端工作区。比 tmux 更现代，内置布局引擎、浮动面板、插件系统、WASM 支持。

### 19. atuin
Rust 写的 Shell 历史管理。SQLite 存储 + 端到端加密同步，`Ctrl+R` 增强版，跨机器共享。

### 20. navi
Rust 写的交互式速查表。`Ctrl+G` 弹窗搜索命令片段，支持自定义 cheatsheet 仓库。

## 第 3 组：Git 与版本控制 (Git & Version Control)

### 21. lazygit
Go 写的 Git TUI。键盘快捷键完成 commit、branch、rebase、stash 等全部操作，效率远超命令行。

### 22. gh (GitHub CLI)
Go 写的 GitHub 官方命令行。`gh pr create`、`gh issue list`、`gh run watch`，管理 GitHub 全流程。

### 23. glab
Go 写的 GitLab CLI。`glab mr create`、`glab ci status`，对标 gh 但用于 GitLab。

### 24. forgit
Bash 写的 fzf + git 集成。`ga`(add)、`glo`(log)、`gcb`(checkout branch) 都走 fzf 交互。

### 25. tig
C 写的 Git 文本浏览器。`tig` 进入交互式 log，`tig blame file` 看逐行作者。

### 26. gitui
Rust 写的 Git TUI。比 lazygit 更快、更轻。支持 stage/unstage、commit、fetch、log 图形化。

### 27. git-absorb
Rust 写的自动 fixup 工具。分析工作区 diff，自动找出应 squash 到哪个 commit，替代手动 rebase -i。

### 28. bfg
Scala 写的 Git 仓库清理。比 `git filter-branch` 快 720×。清除大文件、密码、敏感数据。

### 29. pre-commit
Python 写的 Git hooks 框架。`.pre-commit-config.yaml` 定义 lint/format/test，commit 前自动跑。

### 30. git-delta
见 #5。Git diff 美化器，支持 side-by-side 视图、行号、语法高亮。

## 第 4 组：文件与磁盘管理 (File & Disk)

### 31. lsd
Rust 版 `ls`。图标 + 彩色 + 树形展示。`lsd -l --tree` 比 `ls -R` 优雅得多。

### 32. eza (exa 后继)
Rust 版 `ls`。支持 Git 状态标记、扩展属性、树视图、颜色主题。exa 已停止维护，eza 是社区 fork。

### 33. dust
Rust 版 `du`。直观展示目录占用。`dust /` 看哪个目录最大，比 `du -sh *` 快 10×。

### 34. duf
Go 版 `df`。彩色表格展示磁盘使用，比 `df -h` 可读性强。

### 35. bottom (btm)
Rust 版 `top`/`htop`。CPU、内存、磁盘、网络、进程，图形化 TUI。比 btop 更轻量。

### 36. procs
Rust 版 `ps`。彩色 + 树形 + Docker 进程识别。`procs --tree` 看父子进程关系。

### 37. broot
Rust 写的新一代文件浏览器。`br` 启动，空格切换目录，支持模糊搜索、预览、批量操作。

### 38. nnn
C 写的超轻量文件管理器。不到 4MB，支持插件、批量重命名、磁盘分析、双向面板。

### 39. ranger
Python 写的 Vim 风格文件管理器。三列布局（目录 | 文件列表 | 预览），支持图片/PDF 预览。

### 40. zoxide
Rust 版 `cd`，带智能记忆。`z project` 跳转到最常用的含 "project" 的目录。比 `autojump` 更快。

## 第 5 组：代码与开发 (Code & Development)

### 41. neovim
Vim 的现代化 fork。Lua 配置、内置 LSP、Tree-sitter 语法解析、异步插件。VS Code 之外最流行的编辑器。

### 42. helix
Rust 写的模态编辑器。内置 LSP + Tree-sitter + 多光标，零配置开箱即用。选择→操作模式反直觉但高效。

### 43. tree-sitter
C 写的增量语法解析库。neovim/helix/zed 共用。不依赖正则，能精确理解代码结构（AST）。

### 44. LSP (Language Server Protocol)
微软定义的编辑器-语言服务协议。一个 LSP Server 服务所有编辑器（自动补全、跳转、重构）。

### 45. ast-grep
Rust 写的 AST 级代码搜索替换。用模式代码而非正则匹配。`ast-grep -p 'console.log($A)'` 能匹配所有 log 调用。

### 46. semgrep
Python/OCaml 写的静态分析引擎。用代码模式写规则找 bug/安全漏洞。支持 30+ 语言，规则社区活跃。

### 47. tokei (cloc 替代)
Rust 写的代码行数统计。比 cloc 快 100×，支持 200+ 语言，可输出 JSON/YAML。

### 48. hyperfine
Rust 写的命令行基准测试。`hyperfine 'rg pattern' 'grep -r pattern .'` 科学比较两个命令的性能。

### 49. just
Rust 写的命令运行器。比 Make 更现代的 task runner。`just build` 等同于 Makefile 但语法更简单。

### 50. mise
Rust 写的开发环境管理器。统一管理语言版本（Node/Python/Rust）+ 工具 + 环境变量。asdf + direnv 的合体。

## 第 6 组：构建与包管理 (Build & Package)

### 51. cargo
Rust 官方构建系统+包管理。`cargo build`/`cargo test`/`cargo publish` 一条龙。Cargo.toml 简洁清晰。

### 52. npm / npx
Node.js 包管理。npm 是最大生态（200 万+），npx 执行一次性命令不安装。

### 53. pnpm
比 npm 快 3× 的 Node 包管理。硬链接去重节省 50% 磁盘，monorepo 原生支持（workspace 协议）。

### 54. yarn
Facebook 出品的 npm 替代。确定性安装（lockfile 发明者）、Plug'n'Play 免 node_modules。

### 55. uv / pip
Python 包管理。uv 是 Rust 重写的 pip（快 100×），内置 venv 管理。`uv pip install` 替代 `pip install`。

### 56. poetry
Python 依赖管理+打包。`pyproject.toml` 统一配置 + 确定性 lock 文件。比 pip+requirements.txt 可靠。

### 57. nix
函数式包管理器。可复现构建、原子升级/回滚、开发环境隔离。`nix-shell -p nodejs` 进入临时环境。

### 58. homebrew
macOS/Linux 包管理。`brew install ripgrep` 一行搞定。5000+ formula，非 root 安装。

### 59. scoop
Windows 包管理，无 admin 权限。`scoop install ripgrep`。比 winget 更新更快，社区维护。

### 60. winget
微软官方 Windows 包管理。`winget install BurntSushi.ripgrep.MSVC`。内置 Windows 10+，无需额外安装。

## 第 7 组：容器与基础设施 (Container & Infra)

### 61. docker
容器化标准。应用+依赖打包为一个 image，任何环境一致运行。现代部署的事实标准。

### 62. podman
Red Hat 的 Docker 替代。无 daemon（rootless），兼容 Docker CLI/API。更安全。

### 63. lima
macOS/Linux 上的轻量虚拟机。`limactl start` 启动 Linux VM 跑容器。Colima 基于它。

### 64. colima
基于 Lima 的 Docker 替代。`colima start` 启动容器运行时。macOS 上 Docker Desktop 的免费替代。

### 65. k9s
Go 写的 Kubernetes TUI。终端里管理集群：看 Pod、查日志、exec 进容器、编辑资源。

### 66. helm
K8s 包管理器。`helm install` 部署复杂应用栈。模板化 YAML + 版本化 release。

### 67. terraform
HashiCorp 的基础设施即代码。HCL 描述云资源，`terraform apply` 创建/修改。多云支持。

### 68. ansible
Red Hat 的配置管理。SSH + YAML 批量管理服务器，无需 agent。`ansible-playbook deploy.yml`。

### 69. nixos
Nix 驱动的 Linux 发行版。整个系统配置在一个文件中，可复现、可回滚、原子升级。

### 70. devbox
基于 Nix 的开发环境。`devbox.json` 定义依赖，`devbox shell` 进入隔离环境。比 Docker 轻。

## 第 8 组：网络与 Web (Network & Web)

### 71. curl
HTTP 客户端的事实标准。25 年历史，支持 30+ 协议。`curl -X POST -H ... -d ... https://api` 是 API 调试标配。

### 72. httpie
Python 写的 HTTP 客户端。`http POST api/users name=John` 比 curl 语法直觉，自动 JSON + 彩色。

### 73. websocat
Rust 写的 WebSocket/Socket 客户端。`websocat ws://server` 像 netcat 一样操作 WebSocket。

### 74. mitmproxy
Python 写的中间人代理。拦截/修改/重放 HTTP/HTTPS 流量。调试 API 的神器。

### 75. ngrok
反向代理隧道。`ngrok http 3000` 公网 URL 直通本地端口。内网穿透标配。

### 76. cloudflared
Cloudflare 的 Tunnel 客户端。`cloudflared tunnel` 比 ngrok 更稳定（免费、不限速、自带 HTTPS）。

### 77. frp
Go 写的高性能内网穿透。`frps`(公网) + `frpc`(内网)，支持 TCP/UDP/HTTP/HTTPS。国产自建首选。

### 78. tailscale
基于 WireGuard 的零配置 VPN。设备间 P2P 直连，NAT 穿透。`tailscale up` 即组网。

### 79. wireguard
Linux 内核级 VPN。比 OpenVPN 快 4×，配置超简单（几行公钥私钥）。现代 VPN 标准。

### 80. nmap
C 写的网络扫描器。`nmap -sV 192.168.1.0/24` 扫描局域网所有设备和服务。25 年经典。

## 第 9 组：数据与数据库 (Data & Database)

### 81. sqlite
嵌入式 SQL 数据库。一个文件 = 一个数据库，零配置、零服务器。全球部署量最大的数据库（每个手机里都有）。

### 82. duckdb
嵌入式列式分析数据库。SQLite 的分析版。`SELECT * FROM 'data.csv'` 直接查 CSV/Parquet，比 Pandas 快 10-100×。

### 83. postgresql
"世界上最先进的开源关系型数据库"。扩展性极强（PostGIS、pgvector、TimescaleDB），JSON/全文搜索/向量全能。

### 84. redis
内存数据结构服务器。缓存/队列/PubSub/分布式锁。百微秒级延迟，单线程却极快。

### 85. clickhouse
列式 OLAP 数据库。面向分析场景，万亿行数据亚秒级查询。比传统数据库快 100-1000×。

### 86. grafana
Go 写的数据可视化平台。对接 Prometheus/InfluxDB/PostgreSQL 等，实时仪表盘 + 告警。

### 87. prometheus
Go 写的监控告警系统。时序数据库 + PromQL 查询 + AlertManager。云原生监控事实标准。

### 88. vector
Rust 写的可观测性数据管道。采集→转换→路由，替代 Logstash/Fluentd。单核处理 10TB/天。

### 89. fluentd
Ruby/C 写的统一日志层。500+ 插件，采集各种来源的日志统一输出。CNCF 毕业项目。

### 90. datadog
商业可观测性平台。APM + 日志 + 基础设施 + RUM 一体化。闭源，SaaS 模式。

## 第 10 组：AI/ML 与现代工具 (AI/ML & Modern)

### 91. llama.cpp
C++ 写的 LLM 推理引擎。GGUF 量化模型在消费级硬件上跑。纯 CPU 也能跑 70B 模型。底层是 ggml 张量库。

### 92. ollama
Go 写的本地 LLM 运行器。`ollama run llama3` 一行跑模型。基于 llama.cpp，OpenAI 兼容 API。

### 93. open-webui
Python/TS 写的 LLM 聊天 Web 界面。类 ChatGPT 体验，对接 Ollama/OpenAI。插件系统 + RAG + 多用户。

### 94. aider
Python 写的 AI 编程助手终端。`aider --model deepseek` 在终端里对话式改代码。支持多文件编辑 + Git 自动提交。

### 95. open-interpreter
Python 写的 AI 系统控制。让 LLM 在你的电脑上执行代码。`interpreter.chat("清理桌面")` 即调即用。

### 96. whisper
OpenAI 开源语音识别模型。C++ (whisper.cpp) 可在 CPU 上实时转录，本地离线运行。

### 97. stable-diffusion
开源文生图模型。Stability AI 发布。配合 ComfyUI/A1111 WebUI 搭建图像生成管线。

### 98. comfyui
节点式 AI 图像生成工作流。拖拽节点连管线，比 A1111 灵活 10×。支持 SD/Flux/视频生成。

### 99. langchain
Python/JS 写的 LLM 应用框架。链式调用、Agent、RAG、Memory 等抽象。生态最全但有"过度抽象"争议。

### 100. dspy
Stanford 的声明式 LLM 编程框架。写程序逻辑，自动优化 prompt。比 LangChain 更底层，更关注"编译器"而非"组件"。
