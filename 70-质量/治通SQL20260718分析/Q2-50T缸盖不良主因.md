# Q2-50T 缸盖密封不良主因定位分析

> 分析时间：2026-07-17
> 数据源：`zt_cyl_head_50t_seal`（77.3万条，2018-12-17 ~ 2026-04-13）
> 对比基准：50T 合格率 76.8%，全厂缸盖最低（NF1 85.4% / EVO 82.3% / 375T 84.0% / GB6 98.3%）

---

## 一、分析目的

50T 缸盖气密合格率仅 76.8%，为全厂缸盖产品族最低。本报告定位不良主因，输出可执行的管理行动。

---

## 二、使用的 SQL

### 2.1 综合结果分布

```sql
SELECT `气密综合结果`, COUNT(*) as cnt
FROM `zt_cyl_head_50t_seal`
GROUP BY `气密综合结果`
ORDER BY cnt DESC;
```

| 气密综合结果 | 件数 | 占比 |
|-------------|------|------|
| 合格 | 624,179 | 76.17% |
| 不合格 | 188,300 | 22.98% |
| (空) | 7,067 | 0.86% |

> 合格率 = 624,179 ÷ (624,179 + 188,300) = **76.82%**

### 2.2 分通道不良 Pareto

```sql
SELECT '水道' as ch, COUNT(*) as fail_cnt FROM `zt_cyl_head_50t_seal` WHERE `水道结果`='不合格'
UNION ALL
SELECT '油道', COUNT(*) FROM `zt_cyl_head_50t_seal` WHERE `油道结果`='不合格'

SELECT '气道', COUNT(*) FROM `zt_cyl_head_50t_seal` WHERE `气道结果`='不合格'

UNION ALL
SELECT '流量', COUNT(*) FROM `zt_cyl_head_50t_seal` WHERE `流量结果`='不合格'
```

### 2.4 多通道并发不良

```sql
SELECT
  (CASE WHEN `水道结果`='不合格' THEN 1 ELSE 0 END +
   CASE WHEN `油道结果`='不合格' THEN 1 ELSE 0 END +

```

### 2.5 月度趋势

```sql
SELECT
  DATE_FORMAT(STR_TO_DATE(`时间`,'%Y/%m/%d %H:%i:%s'), '%Y-%m') as mon,
  COUNT(*) as total,
  SUM(CASE WHEN `气密综合结果`='合格' THEN 1 ELSE 0 END) as ok,
  SUM(CASE WHEN `气密综合结果`='不合格' THEN 1 ELSE 0 END) as ng,
  ROUND(100.0 * SUM(CASE WHEN `气密综合结果`='合格' THEN 1 ELSE 0 END) /
    (SUM(CASE WHEN `气密综合结果`='合格' THEN 1 ELSE 0 END) +
     SUM(CASE WHEN `气密综合结果`='不合格' THEN 1 ELSE 0 END)), 1) as pass_rate
FROM `zt_cyl_head_50t_seal`
WHERE `气密综合结果` IN ('合格','不合格')
GROUP BY mon ORDER BY mon;
```

### 2.6 水道泄漏量分布

```sql
SELECT
  CASE
    WHEN leak_val < 0 THEN '负值' WHEN leak_val >= 0 AND leak_val < 5 THEN '0~5'
    WHEN leak_val >= 5 AND leak_val < 10 THEN '5~10'
    WHEN leak_val >= 10 AND leak_val < 20 THEN '10~20'
    WHEN leak_val >= 20 AND leak_val < 50 THEN '20~50'
    WHEN leak_val >= 50 AND leak_val < 100 THEN '50~100'
    WHEN leak_val >= 100 THEN '>=100'
  END as rng, COUNT(*) as cnt, ROUND(AVG(leak_val),1) as avg_val
FROM (
  SELECT CAST(REGEXP_SUBSTR(`水道数据`, '[-]?[0-9]+\\.?[0-9]*(?= *(ml/min|cm3/mn))') AS DECIMAL(10,2)) as leak_val
  FROM `zt_cyl_head_50t_seal`
  WHERE `水道结果`='不合格' AND `水道数据` REGEXP '[0-9]+\\.?[0-9]* *(ml/min|cm3/mn)'
) t WHERE leak_val IS NOT NULL
GROUP BY rng ORDER BY MIN(leak_val);
```

### 2.7 空结果分析

## 四、结论

### 4.1 根因定位：密封面/结合面系统性问题，非个别通道工艺缺陷

**证据链**：

1. **多通道并发特征**：79% 不良件 5 通道以上同时失效，仅 0.2% 为单通道不良。如果是加工缺陷（如某个油孔钻偏），应表现为该通道单独不良；5-7 通道同时不良指向**密封整体失效**——缸盖与缸体结合面平面度、密封垫压缩均匀性、或螺栓预紧力不足。

2. **通道分化规律**：水道（8.9%）和 PVC-BE（5.3%）不良率远低于其余 5 通道（18-24%）。水道和 PVC-BE 位于缸盖的不同位置/密封环带，其较低的失效率说明密封缺陷**在空间上有选择性**——不是整个密封面均匀失效，而是特定区域的密封环带首先失效。

3. **泄漏量分布**：水道不良中 57% 在 10-50 ml/min（中度至严重泄漏），非临界超差；另有 8.6% 为 LARGE LEAK（灾难泄漏），16.1% 为 PRESSURE LOW（无法建立压力）。这表明失效模式**从轻微渗漏到完全失压的全谱分布**，与密封面微观不平度+宏观变形的叠加模式一致。

4. **2022-05 灾难月**：合格率骤降至 29.3%（10个生产日），随后恢复至 70%+。这极可能是**批次性密封垫/缸盖毛坯质量问题**，而非设备/工装渐变衰退。需要核实当时是否有供应商切换或来料批次异常。

5. **与 GB6 的差距**：GB6 合格率 98.3%，50T 仅 76.8%，差 21.5 个百分点。两款产品在同一个工厂生产，设备/人员/管理条件相似，差距应在**产品设计**（密封结构差异）或**毛坯/密封垫供应链质量**上。

### 4.2 管理行动建议

| 优先级 | 行动 | 责任人 | 预期效果 |
|--------|------|--------|---------|
| **P0** | 抽查 50T 缸盖结合面平面度（三坐标），对比图纸公差，确认是否超差 | 质量/机加 | 如平面度超差→机加工序整改 |
| **P0** | 对比 50T 与 GB6 的密封结构设计差异（密封垫层数/材料/螺栓布局/扭矩规格），输出差异报告 | 技术/工艺 | 找到设计层面差距 |
| **P1** | 核查 2022-05 的生产记录：毛坯批次、密封垫供应商批次、设备维修记录 | 生产/质量 | 还原灾难月根因，防止重现 |
| **P1** | 空结果 7,067 条数据修复：检测系统综合结果汇总逻辑修正；历史空结果中 5,729 条主模式应补标为"不合格" | IT/设备 | 数据质量修复 |
| **P2** | 气道传感器负值占比 26.2%，排查气道检测工位传感器校准状态 | 设备/计量 | 减少传感器噪声对判断的干扰 |
| **P2** | 建立 50T 缸盖密封合格率 SPC 控制图（按日），阈值≤80% 自动预警 | 质量 | 实时监控，早发现异常 |

### 4.3 一句话结论

**50T 缸盖密封不良不是某个通道的加工问题，而是密封面/结合面系统性问题——最可能的原因是缸盖平面度超差或密封垫压缩不均匀，导致多通道同时泄漏。水道和 PVC-BE 的低不良率说明密封失效在空间上有选择性，指向特定区域的结构弱点。**

## 五、数据局限性

1. **检测数据列为文本格式**：泄漏量提取依赖正则匹配，可能遗漏格式变体；气道"其他文本"类 118,222 条未能分类（含空格、乱码"SENSOR ERR."、"噜噜噜"等）。
2. **时间列为字符串**：`STR_TO_DATE` 转换可能因格式异常丢失少量记录，已通过限定 `IN ('合格','不合格')` 规避。
3. **空综合结果 7,067 条**：81% 明显是多通道不良但综合结果为空，未计入不合格统计；本报告的主要指标均按"有明确合格/不合格标记"的记录计算，实际不良率略高于报告值。
4. **2022-05 灾难月的根因**：仅有检测数据，无同期生产记录（毛坯批次/供应商/设备维修日志），无法确定具体诱因。
5. **数据截止 2026-04-13**：2026-04 仅 489 条记录，Q2 实际数据未知。当前合格率趋势判断基于 2025-01 ~ 2026-03 的数据。
6. **无缸体配对数据**：密封是缸盖+缸体+密封垫的组合性能，仅有缸盖侧数据，无法排除缸体侧因素的贡献。
