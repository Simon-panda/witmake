# P2-检测节拍分析

> 基于 zt_cyl_block_seal（缸体密封 113.8 万条）和 zt_cyl_head_50t_seal（50T 缸盖密封 82.0 万条）的时间戳节拍分析
> 生成时间：2026-07-17

---

## 一、分析目的

通过密封检测表的时间戳间隔，反推各设备/工序的**实际生产节拍**（秒/件），识别：
1. 各设备节拍基线（中位数/P90）
2. 日内产出节奏（高峰/低谷时段）
3. 异常长间隔的时段聚类（设备等待/异常线索）
4. 节拍效率的长期变化趋势

## 三、分析①：节拍基线分布（中位数/P90）

### 3.1 缸体密封（zt_cyl_block_seal）— 分设备

**方法**：按设备分组，计算相邻检测时间差（排除 >30 分钟的班次/停机间隔），用去重后的唯一时间戳保证准确性。设备 8/9 因批量检测，额外给出「单件估算节拍」。

**SQL**：

```sql
-- 去重后百分位计算（完整SQL见 sql_p1_percentile_v2.sql）
WITH unique_ts AS (
  SELECT `设备编号`, `检测时间` FROM zt_cyl_block_seal WHERE `设备编号` IN ('8','9')
  GROUP BY `设备编号`, `检测时间`
  UNION ALL
  SELECT `设备编号`, `检测时间` FROM zt_cyl_block_seal WHERE `设备编号` NOT IN ('8','9')
),
diffs AS (
  SELECT `设备编号`,
    TIMESTAMPDIFF(SECOND, LAG(`检测时间`) OVER (PARTITION BY `设备编号` ORDER BY `检测时间`), `检测时间`) AS time_diff_sec
  FROM unique_ts
),
filtered AS (SELECT * FROM diffs WHERE time_diff_sec IS NOT NULL AND time_diff_sec <= 1800),
ranked AS (
  SELECT *, ROW_NUMBER() OVER (PARTITION BY `设备编号` ORDER BY time_diff_sec) AS rn,
         COUNT(*) OVER (PARTITION BY `设备编号`) AS cnt FROM filtered
)
SELECT `设备编号`,
  ROUND(AVG(CASE WHEN rn IN (FLOOR((cnt+1)/2),CEIL((cnt+1)/2)) THEN time_diff_sec END),1) AS 中位数秒,
  ROUND(MAX(CASE WHEN rn=CEIL(cnt*0.9) THEN time_diff_sec END),1) AS P90秒
FROM ranked GROUP BY `设备编号`;
```

**结果**：

| 设备 | 类型 | 批次中位(秒) | 批次P90(秒) | 平均批次件数 | 单件中位(秒) | 单件P90(秒) | 单件中位(分) |
|------|------|------------|-----------|------------|------------|-----------|------------|
| 5 | 单件 | 183 | 290 | 1.0 | 183 | 290 | 3.0 |
| 7 | 单件 | 199 | 362 | 1.0 | 199 | 362 | 3.3 |
| 4 | 单件 | 211 | 404 | 1.0 | 211 | 404 | 3.5 |
| 10 | 单件 | 223 | 505 | 1.4 | 223 | 505 | 3.7 |
| 3 | 单件 | 225 | 459 | 1.0 | 225 | 459 | 3.8 |
| 6 | 单件 | 238 | 446 | 1.0 | 238 | 446 | 4.0 |
| 1 | 单件 | 240 | 366 | 1.0 | 240 | 366 | 4.0 |
| 2 | 单件 | 258 | 497 | 1.0 | 258 | 497 | 4.3 |
| **9** | **批量** | **233** | **570** | **17.9** | **13.0** | **31.8** | **0.2** |
| **8** | **批量** | **241** | **347** | **14.6** | **16.5** | **23.8** | **0.3** |

**关键结论**：

1. **设备分两个梯队**：
   - 快速梯队（8/9）：新式批量检测台，单件节拍仅 13-17 秒，是旧设备的 **10-15 倍**
   - 常规梯队（1-7,10）：单件节拍 183-258 秒（3-4 分钟），设备 5 最快（3.0 分），设备 2 最慢（4.3 分）

2. **设备间差异显著**：最快与最慢之间差距达 41%（183s vs 258s），设备 2 比设备 5 每件多花 1.3 分钟

3. **P90 波动大**：设备 2 的 P90 达 497 秒（8.3 分钟），说明存在频繁的短时等待

### 3.2 50T 缸盖密封（zt_cyl_head_50t_seal）— 整体

**方法**：时间列是字符串格式（`2021/06/28 18:24:52`），需 `STR_TO_DATE` 转换后去重计算。

**SQL**：

```sql
WITH unique_ts AS (
  SELECT DISTINCT STR_TO_DATE(`时间`,'%Y/%m/%d %H:%i:%s') AS dt FROM zt_cyl_head_50t_seal
),
diffs AS (SELECT TIMESTAMPDIFF(SECOND, LAG(dt) OVER (ORDER BY dt), dt) AS diff FROM unique_ts),
filtered AS (SELECT diff FROM diffs WHERE diff IS NOT NULL AND diff <= 1800),
ranked AS (SELECT diff, ROW_NUMBER() OVER (ORDER BY diff) AS rn, COUNT(*) OVER () AS cnt FROM filtered)
SELECT ROUND(AVG(CASE WHEN rn IN (FLOOR((cnt+1)/2),CEIL((cnt+1)/2)) THEN diff END),1) AS 中位数,
       ROUND(MAX(CASE WHEN rn=CEIL(cnt*0.9) THEN diff END),1) AS P90 FROM ranked;
```

**结果**：

| 指标 | 值 |
|------|-----|
| 有效间隔数 | 811,575 |
| 平均节拍 | 130.6 秒（2.2 分） |
| 中位节拍 | 103.0 秒（1.7 分） |
| P90 节拍 | 251 秒（4.2 分） |

**数据局限**：50T 表无设备编号列，无法分设备对比；且数据截止 2026-04-13，缺少近 3 个月数据。

## 八、数据局限性

1. **设备 8/9 的单件节拍为估算值**：基于「批次节拍÷平均批次件数」，实际单件节拍可能不同（批次内各工件可能是并行的）。需接入 MES 工单数据精确计算。

2. **50T 缸盖密封表无设备编号**：无法做分设备对比，且数据截止 2026-04-13，近 3 个月数据缺失。

3. **间隔时间 ≠ 纯加工时间**：时间戳间隔包含了上下料、人工检查等辅助时间，实际机加工时间可能更短。

4. **异常间隔阈值依赖 P90**：各设备 P90 值差异大（290-570s），3×P90 的阈值对不同设备的敏感度不同。

5. **设备 10 数据量少**（1.2 万条，记录戳比 1.4），早期数据存在大量 0 间隔，统计可靠性较低。

6. **产品型号未纳入分析**：不同产品型号的节拍可能有显著差异，本次仅按设备汇总。
