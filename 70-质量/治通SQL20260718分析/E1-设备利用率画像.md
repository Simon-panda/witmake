# E1 — 检测设备利用率画像

> 生成时间：2026-07-17  
> 数据源：zt_server_data（密封表 3 张 + 断芯表 3 张）  
> 分析范围：各表全量数据，截止 2026-07-17

---

## 一、分析目的

基于密封检测表（zt_cyl_block_seal / zt_cyl_head_evo_seal / zt_cyl_head_375t_seal）的 `设备编号` 字段 + 断芯 3 台设备（zt_cyl_block_brk_core_1/2/3），完成四维设备利用率画像：

| 维度 | 内容 |
|------|------|
| ① 记录排名 | 每台设备的记录量、活跃天数、日均检测数排名 |
| ② 时段密度 | 每台设备按小时的活跃分布 —— 评估稼动率 |
| ③ 闲置清单 | 连续 >7 天无记录的设备 + 当前闲置状态 |
| ④ 断芯均衡 | 断芯 1/2/3 三台设备的任务分配均衡度 |

## 二、使用的 SQL

### 2.1 设备记录量/活跃天数/日均检测（密封表）

```sql
-- zt_cyl_block_seal（缸体密封，时间列 = datetime）
SELECT `设备编号` AS 设备, COUNT(*) AS 记录量,
  COUNT(DISTINCT DATE(`检测时间`)) AS 活跃天数,
  ROUND(COUNT(*)/COUNT(DISTINCT DATE(`检测时间`)),1) AS 日均检测,
  MIN(DATE(`检测时间`)) AS 首日, MAX(DATE(`检测时间`)) AS 末日
FROM zt_cyl_block_seal
GROUP BY `设备编号` ORDER BY 记录量 DESC;

-- zt_cyl_head_evo_seal（缸盖EVO密封，时间列 = 字符串 'YYYY/MM/DD HH:MM:SS'）
SELECT `设备编号` AS 设备, COUNT(*) AS 记录量,
  COUNT(DISTINCT DATE(STR_TO_DATE(`时间`,'%Y/%m/%d %H:%i:%s'))) AS 活跃天数,
  ROUND(COUNT(*)/COUNT(DISTINCT DATE(STR_TO_DATE(`时间`,'%Y/%m/%d %H:%i:%s'))),1) AS 日均检测,
  MIN(DATE(STR_TO_DATE(`时间`,'%Y/%m/%d %H:%i:%s'))) AS 首日,
  MAX(DATE(STR_TO_DATE(`时间`,'%Y/%m/%d %H:%i:%s'))) AS 末日
FROM zt_cyl_head_evo_seal
GROUP BY `设备编号` ORDER BY 记录量 DESC;

-- zt_cyl_head_375t_seal（缸盖375T密封，时间列 = 字符串 'YYYY-MM-DD HH:MM:SS'）
SELECT `设备编号` AS 设备, COUNT(*) AS 记录量,
  COUNT(DISTINCT DATE(`时间`)) AS 活跃天数,
  ROUND(COUNT(*)/COUNT(DISTINCT DATE(`时间`)),1) AS 日均检测,
  MIN(DATE(`时间`)) AS 首日, MAX(DATE(`时间`)) AS 末日
FROM zt_cyl_head_375t_seal
GROUP BY `设备编号` ORDER BY 记录量 DESC;
```

### 2.2 断芯设备记录量/活跃天数/日均检测

```sql
SELECT '断芯1' AS 设备, COUNT(*) AS 记录量,
  COUNT(DISTINCT DATE(`时间`)) AS 活跃天数,
  ROUND(COUNT(*)/COUNT(DISTINCT DATE(`时间`)),1) AS 日均检测,
  MIN(DATE(`时间`)) AS 首日, MAX(DATE(`时间`)) AS 末日
FROM zt_cyl_block_brk_core_1
UNION ALL
SELECT '断芯2', COUNT(*), COUNT(DISTINCT DATE(`时间`)),
  ROUND(COUNT(*)/COUNT(DISTINCT DATE(`时间`)),1),
  MIN(DATE(`时间`)), MAX(DATE(`时间`))
FROM zt_cyl_block_brk_core_2
UNION ALL
SELECT '断芯3', COUNT(*), COUNT(DISTINCT DATE(`时间`)),
  ROUND(COUNT(*)/COUNT(DISTINCT DATE(`时间`)),1),
  MIN(DATE(`时间`)), MAX(DATE(`时间`))
FROM zt_cyl_block_brk_core_3;
```

### 2.3 小时活跃密度

```sql
-- zt_cyl_block_seal
SELECT `设备编号`, HOUR(`检测时间`) AS 小时, COUNT(*) AS 检测数
FROM zt_cyl_block_seal
GROUP BY `设备编号`, HOUR(`检测时间`) ORDER BY `设备编号`, 小时;

-- zt_cyl_head_evo_seal
SELECT `设备编号`, HOUR(STR_TO_DATE(`时间`,'%Y/%m/%d %H:%i:%s')) AS 小时, COUNT(*) AS 检测数
FROM zt_cyl_head_evo_seal
GROUP BY `设备编号`, HOUR(STR_TO_DATE(`时间`,'%Y/%m/%d %H:%i:%s')) ORDER BY `设备编号`, 小时;

-- zt_cyl_head_375t_seal
SELECT `设备编号`, HOUR(`时间`) AS 小时, COUNT(*) AS 检测数
FROM zt_cyl_head_375t_seal
GROUP BY `设备编号`, HOUR(`时间`) ORDER BY `设备编号`, 小时;

-- 断芯三台
SELECT '断芯1' AS 设备, HOUR(`时间`) AS 小时, COUNT(*) AS 检测数
FROM zt_cyl_block_brk_core_1 GROUP BY HOUR(`时间`)
UNION ALL SELECT '断芯2', HOUR(`时间`), COUNT(*) FROM zt_cyl_block_brk_core_2 GROUP BY HOUR(`时间`)
UNION ALL SELECT '断芯3', HOUR(`时间`), COUNT(*) FROM zt_cyl_block_brk_core_3 GROUP BY HOUR(`时间`)
ORDER BY 设备, 小时;
```

### 2.4 连续 >7 天闲置检测

```sql
-- 以 zt_cyl_block_seal 为例（其余表逻辑相同，仅时间列处理方式不同）
WITH daily AS (
  SELECT `设备编号`, DATE(`检测时间`) AS dt
  FROM zt_cyl_block_seal
  GROUP BY `设备编号`, DATE(`检测时间`)
),
gaps AS (
  SELECT `设备编号`, dt,
    LAG(dt) OVER (PARTITION BY `设备编号` ORDER BY dt) AS prev_dt,
    DATEDIFF(dt, LAG(dt) OVER (PARTITION BY `设备编号` ORDER BY dt)) AS gap_days
  FROM daily
)
SELECT `设备编号`, dt AS 断点日期, prev_dt AS 上次活跃, gap_days AS 间隔天数
FROM gaps WHERE gap_days > 7
ORDER BY `设备编号`, dt;
```

### 2.5 当前闲置天数

```sql
-- 各表最后活跃日期
SELECT `设备编号`, MAX(DATE(`检测时间`)) AS 最后活跃,
  DATEDIFF(CURDATE(), MAX(DATE(`检测时间`))) AS 闲置至今
FROM zt_cyl_block_seal GROUP BY `设备编号` ORDER BY 闲置至今 DESC;
```

### 2.6 断芯任务分配均衡度

```sql
-- 按月分布
SELECT DATE_FORMAT(`时间`,'%Y-%m') AS 月份,
  SUM(CASE WHEN tbl=1 THEN 1 ELSE 0 END) AS 断芯1,
  SUM(CASE WHEN tbl=2 THEN 1 ELSE 0 END) AS 断芯2,
  SUM(CASE WHEN tbl=3 THEN 1 ELSE 0 END) AS 断芯3,
  COUNT(*) AS 合计
FROM (
  SELECT `时间`, 1 AS tbl FROM zt_cyl_block_brk_core_1 UNION ALL
  SELECT `时间`, 2 FROM zt_cyl_block_brk_core_2 UNION ALL
  SELECT `时间`, 3 FROM zt_cyl_block_brk_core_3
) t GROUP BY DATE_FORMAT(`时间`,'%Y-%m') ORDER BY 月份;
```

## 四、结论（管理行动导向）

### 1. 缸体密封设备 8/9 是高价值资产 —— 需要重点保障

设备 8/9 承担了缸体密封 **42% 的总记录量**（476,142 / 1,137,643），日均 2,570 件是其他设备的 9-17 倍。**这两台设备一旦故障，产能将断崖式下降。**
- **行动：** 将设备 8/9 列入关键设备清单，建立预防性维护计划；备足易损件。

### 2. 缸盖 EVO 密封 3 台设备已停用 178 天 —— 确认是否退役

三台 evo 密封设备全部在 2026-01-20 停用，无后续记录。如已退役，应清理对应产线配置；如应运行而未运行，需排查设备故障或产线调度问题。

### 3. 缸盖 375T 密封 2 台设备停用 44 天 —— 确认原因

两台 375T 设备 6 月 3 日后无记录。需与生产确认是产线调整还是设备故障。

### 4. 缸体设备 3 已闲置 16 天 —— 立即核查

设备 3 最后活跃 2026-07-01，至今 16 天无记录。如果非计划停机，需立即排查。

### 5. 断芯设备任务分配严重失衡 —— 重新配平

当前断芯3 承载大部分任务（7月 8,612 vs 断芯1 757 vs 断芯2 1,997）。断芯1 从 2026-04 开始骤降，目前接近停用状态。
- **行动：** 核查断芯1 是否故障；如正常，将断芯3 的任务量分流 30-40% 到断芯1。
- **参考基准：** 2025-10 月的 36:26:38 配比是历史最佳均衡点。

### 6. 所有设备 7-8 时、17 时为换班低谷 —— 排产优化空间

各设备在 7-8 时和 17 时的检测量骤降至峰值的 30-50%。如果这是班次交接停机，可评估压缩交接时间（例如从 1h 压缩到 30min），每台主力设备每天可多产出约 2,500-5,000 件。

## 五、数据局限性

| 局限 | 影响 | 说明 |
|------|------|------|
| 无设备运行状态字段 | 无法区分"闲置"是停机/故障/无任务/计划停产 | 闲置天数 ≠ 故障天数 |
| 无任务队列数据 | 无法判断任务分配是人为调度还是自动均衡 | 断芯分配不均可能是产能不足而非调度问题 |
| evo 密封表 44-47% 记录时间解析失败 | 小时密度分析不完整 | STR_TO_DATE 对部分记录格式失败，需排查原始时间字符串格式 |
| 无节拍时间数据 | "日均检测"不反映实际产能饱和度 | 设备可能只开一班但单班产能未满 |
| 封面时间范围不一致 | 跨表对比需注意时间窗口 | evo 密封 2023-01→2026-01，block_seal 2024-08→2026-07 |
