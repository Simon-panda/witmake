# Q4-断芯尺寸过程能力分析

**分析日期**：2026-07-17
**数据源**：zt_cyl_block_brk_core_1/2/3（MySQL zt_server_data）
**分析者**：Hermes Agent (quality profile)

---

## 一、分析目的

对三台缸体断芯检测设备（brk_core_1/2/3）的 57 列实测尺寸数据进行过程能力评估，包括：
1. 各测量列的描述性统计（均值/标准差/极差）
2. 设备间同名列的系统性偏差对比
3. 异常值率排名（找出最不稳定尺寸）
4. 不合格记录的根因线索（异常集中度最高的检测项）

注意：无规格限数据，无法计算 CPK。用"设备间偏差"和"离散度排名"替代过程能力指数。

## 四、Part ② 设备间系统偏差对比

### 方法说明

由于 brk_core_2 数据被大量探针故障值（0 值和极端值）污染，直接比较均值会产生误导。采用两种策略：
1. **原始均值差**：直接相减（反映含故障数据的综合偏差）
2. **OK子集均值差**：仅比较合格记录的均值（排除NG的干扰）

## 六、Part ④ 不合格根因分析

### 6.1 核心发现：尺寸不是NG的主因

**SQL**：
```sql
-- 完整SQL见 F:\zt_analysis\sql_p4c.sql
SELECT `测量结果`, `尺寸结果`, COUNT(*) as cnt
FROM zt_cyl_block_brk_core_1
GROUP BY `测量结果`, `尺寸结果`;

-- NG根因分解（完整SQL见 F:\zt_analysis\sql_ng_breakdown.sql）
SELECT `测量结果`,
  SUM(CASE WHEN `光通检测`='不合格' THEN 1 ELSE 0 END) as 光通NG,
  SUM(CASE WHEN `视觉检测`='不合格' THEN 1 ELSE 0 END) as 视觉NG,
  SUM(CASE WHEN `物理探针检测`='不合格' THEN 1 ELSE 0 END) as 探针NG,
  SUM(CASE WHEN `流量检测`='不合格' THEN 1 ELSE 0 END) as 流量NG,
  SUM(CASE WHEN `H333防错`='不合格' THEN 1 ELSE 0 END) as H333NG,
  SUM(CASE WHEN `缸套检测`='不合格' THEN 1 ELSE 0 END) as 缸套NG,
  COUNT(*) as total
FROM zt_cyl_block_brk_core_1
WHERE `测量结果` IN ('合格','不合格')
GROUP BY `测量结果`;
```

| 测量结果 | 尺寸结果 | 记录数 | 占比 |
|----------|----------|--------|------|
| 合格 | 合格 | 217,891 | 84.4% |
| **不合格** | **合格** | **38,035** | **14.7%** |
| **不合格** | **不合格** | **2,181** | **0.8%** |

**94.6% 的不合格记录中，尺寸检测结果是"合格"的！** 这说明断芯检测的 NG 判定的主要驱动因素不是尺寸测量，而是其他检测项。

## 七、结论与管理建议

### 7.1 核心结论

1. **尺寸测量过程能力整体可接受**：定位孔径（CV=0.02%）、孔中心距（CV=0.003%）精度极优，F100/F200 中等。F30x 系列偶发探针异常（1.5~2.1%），但不影响 NG 判定。

2. **brk_core_2 存在严重数据质量问题**：
   - H301/H302/H305 的 Y/Z 通道 OK 记录 σ 异常小（疑似输出固定值）
   - 大量探针回缩/断电时记录为 0 值（F301 max=0, 定位 min=0, 孔距 min=0）
   - 缸套距离与 _1 量纲不同（同一列名、不同物理量）——数据库设计缺陷
   - NG 率持续 24%+，两年无改善

3. **NG 判定的根因不是尺寸**：
   - brk_core_1：**缸套检测**贡献 67% 的 NG（首要改善目标）

## 八、数据局限性

1. **无规格限**：无法计算 CPK/PPK，只能用离散度和设备间偏差替代过程能力评估
2. **brk_core_2 数据污染严重**：0 值、极端值（2147）、通道固定输出等问题导致多数统计指标失真，Part ② 的设备偏差对比仅限于 OK 子集
3. **brk_core_3 结构不兼容**：面检测编码需更深入的解码才能做详细的根因分析，已超出本次分析范围
4. **缸套距离量纲不一致**：_1 和 _2 的同名列记录不同物理量，无法直接进行设备间对比
5. **偏度未计算**：F30x 系列受探针回缩极值影响，偏度指标意义有限；且 MySQL 无内置 SKEWNESS 函数，需导出数据后用 Python/SciPy 计算
6. **H303 全系列常数 0**：该测量通道在两台设备上均未启用或已废弃
