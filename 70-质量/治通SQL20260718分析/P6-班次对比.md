# P6-班次产出与质量对比分析

**分析周期**：2026-06-01 ~ 2026-07-17（7周）
**数据源**：zt_cyl_block_seal（缸体密封试漏，113.7万行）+ zt_cyl_block_las_mark（缸体打码，64.6万行）
**分析日期**：2026-07-17

---

## 一、分析目的

验证白班（8:00-20:00）与夜班（20:00-8:00）的班次划分是否合理，对比两班在产量、合格率、异常模式上的差异，识别夜班特有/高发异常，比较周末与工作日的表现差异，输出可落地的管理建议。

---

## 二、使用的SQL（完整可复现）

### 2.1 小时分布验证班次边界

```sql
-- 密封表小时分布
SELECT HOUR(`检测时间`) AS 小时, COUNT(*) AS 记录数
FROM zt_cyl_block_seal
WHERE `检测时间` >= '2026-06-01'
GROUP BY 小时 ORDER BY 小时;

-- 打码表小时分布
SELECT HOUR(`timestamp`) AS 小时, COUNT(*) AS 记录数
FROM zt_cyl_block_las_mark
WHERE `timestamp` >= '2026-06-01'
GROUP BY 小时 ORDER BY 小时;
```

### 2.2 班次产量与合格率总对比

```sql
SELECT 
  CASE 
    WHEN HOUR(`检测时间`) >= 8 AND HOUR(`检测时间`) < 20 THEN '白班(8:00-20:00)'
    ELSE '夜班(20:00-8:00)'
  END AS 班次,
  COUNT(*) AS 检测总数,
  SUM(CASE WHEN `整体检测结果`='合格' THEN 1 ELSE 0 END) AS 合格数,
  SUM(CASE WHEN `整体检测结果`='不合格' THEN 1 ELSE 0 END) AS 不合格数,
  SUM(CASE WHEN `整体检测结果`='可修复' THEN 1 ELSE 0 END) AS 可修复数,
  ROUND(SUM(CASE WHEN `整体检测结果`='合格' THEN 1 ELSE 0 END)/COUNT(*)*100,2) AS 合格率
FROM zt_cyl_block_seal
WHERE `检测时间` >= '2026-06-01'
GROUP BY 班次;
```

### 2.3 打码表异常率验证

```sql
SELECT 
  CASE WHEN HOUR(`timestamp`)>=8 AND HOUR(`timestamp`)<20 THEN '白班' ELSE '夜班' END AS 班次,
  COUNT(*) AS 打码总数,
  SUM(CASE WHEN `error_info` IS NOT NULL AND `error_info`!='' THEN 1 ELSE 0 END) AS 异常数,
  ROUND(SUM(CASE WHEN `error_info` IS NOT NULL AND `error_info`!='' THEN 1 ELSE 0 END)/COUNT(*)*100,2) AS 异常率
FROM zt_cyl_block_las_mark
WHERE `timestamp` >= '2026-06-01'
GROUP BY 班次;
```

### 2.4 分产品班次对比

```sql
SELECT `产品类型`,
  SUM(CASE WHEN HOUR(`检测时间`)>=8 AND HOUR(`检测时间`)<20 THEN 1 ELSE 0 END) AS 白班数,
  ROUND(SUM(CASE WHEN HOUR(`检测时间`)>=8 AND HOUR(`检测时间`)<20 AND `整体检测结果`='合格' THEN 1 ELSE 0 END)
    /NULLIF(SUM(CASE WHEN HOUR(`检测时间`)>=8 AND HOUR(`检测时间`)<20 THEN 1 ELSE 0 END),0)*100,2) AS 白班合格率,
  SUM(CASE WHEN HOUR(`检测时间`)<8 OR HOUR(`检测时间`)>=20 THEN 1 ELSE 0 END) AS 夜班数,
  ROUND(SUM(CASE WHEN (HOUR(`检测时间`)<8 OR HOUR(`检测时间`)>=20) AND `整体检测结果`='合格' THEN 1 ELSE 0 END)
    /NULLIF(SUM(CASE WHEN HOUR(`检测时间`)<8 OR HOUR(`检测时间`)>=20 THEN 1 ELSE 0 END),0)*100,2) AS 夜班合格率
FROM zt_cyl_block_seal
WHERE `检测时间` >= '2026-06-01'
GROUP BY `产品类型`;
```

### 2.5 分设备班次+检测项分解

### 2.7 周末vs工作日

```sql
SELECT 
  CASE WHEN DAYOFWEEK(`检测时间`) IN (1,7) THEN '周末' ELSE '工作日' END AS 日期类型,
  CASE WHEN HOUR(`检测时间`)>=8 AND HOUR(`检测时间`)<20 THEN '白班' ELSE '夜班' END AS 班次,
  COUNT(*) AS 检测总数,
  ROUND(SUM(CASE WHEN `整体检测结果`='合格' THEN 1 ELSE 0 END)/COUNT(*)*100,2) AS 合格率,
  ROUND(COUNT(*)/COUNT(DISTINCT DATE(`检测时间`)),0) AS 日均检测
FROM zt_cyl_block_seal
WHERE `检测时间` >= '2026-06-01'
GROUP BY 日期类型, 班次;
```

### 2.8 换班窗口设备级分析

```sql
SELECT `设备编号`,
  CASE 
    WHEN HOUR(`检测时间`) IN (7,8) THEN '早班交接(7-8点)'
    WHEN HOUR(`检测时间`) IN (19,20) THEN '晚班交接(19-20点)'
    ELSE '正常时段'
  END AS 时段,
  COUNT(*) AS 检测数,
  ROUND(SUM(CASE WHEN `整体检测结果`='不合格' THEN 1 ELSE 0 END)/COUNT(*)*100,2) AS 不合格率
FROM zt_cyl_block_seal
WHERE `检测时间` >= '2026-06-01'
GROUP BY `设备编号`, 时段
HAVING 检测数 > 50;
```

### 2.9 周度趋势


## 四、结论与管理行动

### 核心结论

1. **夜班整体优于白班（+3.52pp合格率，+25.8%产量），且不受产品结构差异影响**——逐产品对比后夜班仍全面领先。两条独立数据线（密封试漏+激光打码）交叉验证一致。

2. **换班交接是最大的质量黑洞**——早班交接窗口(7-8点)不合格率36.52%，晚班交接(19-20点)24.44%，所有设备无一幸免。仅解决换班窗口问题，预估可挽回约3-5pp的整体合格率。

3. **设备10和设备7是系统性异常点**——无论班次、无论工作日/周末，这两台设备的不合格率都在28-38%区间（其他设备多在10-20%），高压油道和箱体是持续高发的失败模式，指向设备本身而非操作因素。

4. **设备6、设备10的班次差异巨大（+13.2pp / +8.5pp）**——同样是操作，夜班比白班在这些设备上表现好得多，表明白班可能存在操作规范、首件校准、或维护流程上的差异。

5. **白班承担了更多高难度产品（PFI、MP/LP_NA的产量是夜班的3.6倍）**——这反映产线排程策略而非能力差异，但客观上拉低了白班整体合格率。

### 管理行动建议

|---|------|-------|--------|---------|

## 五、数据局限性

1. **班次定义基于时间戳推断，非系统记录的班次字段**——8:00-20:00/20:00-8:00是合理近似，但实际班次可能因加班、调休、临时排班而有偏移。建议后期在MES中增加`班次`字段。

2. **打码表与密封表非一一对应**——打码是上道工序，密封试漏是下道工序，存在时间滞后（约数小时到半天），因此不能做精确的逐件追踪对账。

3. **产品类型未做归一化处理**——LP/LP_NA/MP/LP_NA等混写可能包含实际相同的产品型号，当前按原始值统计，部分组的样本量偏小（如MP_NA仅4条）。

4. **仅覆盖缸体产品族**——缸盖、差壳、结构件的班次对比未纳入本次分析，结论不能推广到全厂产线。

5. **7/1-7/12期间数据量偏低**（密封表日均~400-700 vs 正常~700-1000），W28-W29部分日期可能数据未完整同步，周度趋势解读需谨慎。

6. **不含"未检测""测试中"等中间状态的明细分析**——这些状态可能反映设备待机、换模、调试等非生产时间，对理解班次效率差异有额外价值但未纳入本次范围。
