# Q1 — 全产品密封合格率基线与月度趋势

> 生成时间：2026-07-17  
> 数据源：zt_server_data（MySQL 8.0，治通工厂终检/试漏工序）  
> 统计口径：一次合格率 = 合格 / (合格 + 不合格)，排除"测试中""未检测""可修复""异常码""空值"等中间状态

---

## 一、分析目的

建立 7 条产品线（缸体 / 50T / NF1 / GB6 / GL31 / EVO / 375T）密封检测的一次合格率基线，回答四个问题：

1. 各产品线历史总基线合格率是多少？
2. 月度趋势走向如何（上升/下降/平稳）？
3. 最近 3 个月 vs 去年同期有何变化？
4. 哪些月份出现了合格率突变（环比波动 > 3 个百分点）？

---

## 二、使用的 SQL（完整可复现）

### 2.1 总体一次合格率

```sql
-- 示例：缸体
SELECT '缸体' AS 产品,
  SUM(CASE WHEN `整体检测结果` = '合格' THEN 1 ELSE 0 END) AS 合格数,
  SUM(CASE WHEN `整体检测结果` = '不合格' THEN 1 ELSE 0 END) AS 不合格数,
  SUM(CASE WHEN `整体检测结果` IN ('合格','不合格') THEN 1 ELSE 0 END) AS 有效总数,
  COUNT(*) AS 全部记录,
  ROUND(SUM(CASE WHEN `整体检测结果` = '合格' THEN 1 ELSE 0 END) * 100.0
    / NULLIF(SUM(CASE WHEN `整体检测结果` IN ('合格','不合格') THEN 1 ELSE 0 END), 0), 2) AS 一次合格率
FROM zt_cyl_block_seal;

-- 50T: 表 zt_cyl_head_50t_seal, 结果列 `气密综合结果`, 排除空值
-- NF1: 表 zt_cyl_head_nf1_seal, 结果列 `综合结果`, 排除'测试完成''测试中'
-- GB6: 表 zt_cyl_head_gb6_seal, 结果列 `结果`, 排除'检测中'和空值
-- GL31: 表 zt_cyl_head_gl31_seal, 结果列 `综合结果`, 排除'异常码''测试中''测试完成'和空值
-- EVO: 表 zt_cyl_head_evo_seal, 结果列 `检测结果`, 排除'未检测'
-- 375T: 表 zt_cyl_head_375t_seal, 结果列 `检测结果`, 排除'待检测''检测中'
```

### 2.2 月度趋势

```sql
-- 缸体（时间列为 datetime 原生类型）
SELECT DATE_FORMAT(`检测时间`, '%Y-%m') AS month,
  SUM(CASE WHEN `整体检测结果`='合格' THEN 1 ELSE 0 END) AS pass,
  SUM(CASE WHEN `整体检测结果`='不合格' THEN 1 ELSE 0 END) AS fail,
  ROUND(SUM(CASE WHEN `整体检测结果`='合格' THEN 1 ELSE 0 END)*100.0/
    NULLIF(SUM(CASE WHEN `整体检测结果` IN ('合格','不合格') THEN 1 ELSE 0 END),0),2) AS rate
FROM zt_cyl_block_seal
WHERE `整体检测结果` IN ('合格','不合格')
GROUP BY DATE_FORMAT(`检测时间`, '%Y-%m')
ORDER BY month;

-- 50T/NF1/GL31/EVO：时间列为字符串，需 STR_TO_DATE
-- 格式统一为 '%Y/%m/%d %H:%i:%s'（50T/NF1/GL31/EVO）
-- 375T 格式为 '%Y-%m-%d %H:%i:%s'（与前者不同！）

-- GB6：`日期` 为 datetime 原生类型
```

### 2.3 环比突变检测

```sql
-- 对所有产品，使用 LAG() 窗口函数计算环比变动
SELECT * FROM (
  SELECT '缸体' AS 产品, month, pass, fail, rate,
    ROUND(rate - LAG(rate) OVER (ORDER BY month), 2) AS mom_change
  FROM (
    SELECT DATE_FORMAT(`检测时间`, '%Y-%m') AS month,
      ROUND(SUM(CASE WHEN `整体检测结果`='合格' THEN 1 ELSE 0 END)*100.0/
        NULLIF(SUM(CASE WHEN `整体检测结果` IN ('合格','不合格') THEN 1 ELSE 0 END),0),2) AS rate,
      SUM(CASE WHEN `整体检测结果`='合格' THEN 1 ELSE 0 END) AS pass,
      SUM(CASE WHEN `整体检测结果`='不合格' THEN 1 ELSE 0 END) AS fail
    FROM zt_cyl_block_seal WHERE `整体检测结果` IN ('合格','不合格')
    GROUP BY DATE_FORMAT(`检测时间`, '%Y-%m')
  ) t
) t2 WHERE ABS(mom_change) > 3
ORDER BY month;
-- 其余产品同模式，替换表名/时间转换/结果列/排除条件
```

## 三、数据结果

### 3.1 全产品一次合格率基线汇总

| 产品 | 合格数 | 不合格数 | 有效总数 | 全部记录 | 一次合格率 | 数据跨度 |
|------|--------|----------|----------|----------|------------|----------|
| GB6 | 248,754 | 4,423 | 253,177 | 253,189 | **98.25%** | 2022-01 ~ 2026-05 |
| 缸体 | 1,000,036 | 114,741 | 1,114,777 | 1,137,643 | **89.71%** | 2024-08 ~ 2026-07 |
| NF1 | 672,336 | 115,244 | 787,580 | 788,130 | **85.37%** | 2019-09 ~ 2026-05 |
| 375T | 97,059 | 18,552 | 115,611 | 115,616 | **83.95%** | 2023-01 ~ 2026-06 |
| EVO | 125,593 | 26,966 | 152,559 | 152,570 | **82.32%** | 2025-02 ~ 2026-01 |
| 50T | 624,179 | 188,300 | 812,479 | 819,546 | **76.82%** | 2018-12 ~ 2026-04 |
| GL31 | 157,568 | 50,042 | 207,610 | 208,100 | **75.90%** | 2013-04 ~ 2026-07 |

**关键发现：**

- GB6 合格率最优（98.25%），接近零缺陷水平，但 2026-05 出现骤降至 83.43%
- 缸体样本量最大（111 万+有效记录），合格率 89.71% 为第二梯队
- 50T 和 GL31 是薄弱环节，约 1/4 产品一次不合格，需重点关注
- GL31 数据历史最长（2013 年起），但合格率长期低迷，且存在大量月份无数据

### 3.2 月度合格率趋势

#### 缸体（2024-08 ~ 2026-07）

```
2024-08: 89.62% → 2024-12: 90.62% → 2025-06: 91.78%
→ 2025-09: 94.65%（峰值）→ 2025-12: 86.35%（回落）
→ 2026-02: 74.90%（骤降）→ 2026-03: 89.90%（恢复）→ 2026-07: 79.54%
```
- **趋势判断：波动加剧，近期下行。** 2026 年以来合格率从 88%+ 降至 79-82% 区间（排除 3 月异常大月后）
- 2026-03 单月 46.7 万条记录（产量暴增），需确认是否为数据批量导入或产线扩产

#### 50T（2018-12 ~ 2026-04）

```
2018-12: 97.99% → 2020-12: 69.74% → 2022-05: 29.34%（最低点）
→ 2023-06: 82.81% → 2025-04: 86.11%（近期峰值）→ 2026-04: 75.05%
```
- **趋势判断：长期在 70-85% 之间宽幅震荡，无明显改善趋势。** 8 年数据，合格率中位约 75-78%
- 2022-05 暴跌至 29.34%（仅 558 合格 vs 1344 不合格），疑似设备故障或工艺变更

#### NF1（2019-09 ~ 2026-05）

```
2019-09: 94.47% → 2020-05: 97.15%（峰值）→ 2022-12: 74.04%
→ 2025-01: 58.37%（暴跌）→ 2025-05: 90.90%（恢复）→ 2026-05: 79.11%
```
- **趋势判断：明显退化。** 从早期 90%+ 降至近两年 70-80% 区间
- 2025-01 暴跌至 58.37% 为全周期最低（春节月样本少，1980 合格 vs 1412 不合格）

#### GB6（2022-01 ~ 2026-05）

```
2022-01: 99.30% → 2023-12: 98.74% → 2024-06~08: 样本极少（各月 < 15 条）
→ 2025-03: 98.92% → 2025-07: 86.19% → 2026-05: 83.43%
```
- **趋势判断：高基线下的近期恶化。** 历史 98%+ 但近一年波动加剧，2025-07 和 2026-05 出现两次大跌
- 2024-Q3 数据几乎断档（月均 < 5 条），可能是产线停产或数据采集故障

#### GL31（2013-04 ~ 2026-07）

```
2013-04: 67.57% → 2019-10: 93.05%（短暂高峰）→ 2020~2023: 数据严重不连续
→ 2024-06: 50.06%（低谷）→ 2025-09: 57.93% → 2026-03: 80.55%
```
- **趋势判断：数据质量极差，无法形成可靠趋势线。** 存在大量缺月、零样本月（如 2021-02/07、2023-08/12 无合格记录）
- 即使有数据的月份，合格率长期在 50-80% 低位徘徊

#### EVO（2025-02 ~ 2026-01）

```
2025-02: 90.74% → 2025-03: 56.00%（暴跌）→ 2025-09: 86.65%
→ 2025-12: 83.96% → 2026-01: 83.41%
```
- **趋势判断：投产初期波动，趋于稳定。** 仅 12 个月数据，初期极端波动（单月骤降 34.74pp），后期收敛至 82-84%
- 注意：EVO 表有 56,978 条记录的时间列为 NULL（占比 37%），无法纳入月度分析

#### 375T（2023-01 ~ 2026-06）

```
2023-01: 91.74% → 2023-12: 70.91%（年度最低）→ 2024-12: 49.64%
→ 2025-01: 36.05%（全周期最低）→ 2025-09: 90.95%（恢复）→ 2026-05: 89.41%
```
- **趋势判断：触底反弹。** 2024-Q4~2025-Q1 为质量灾难期（合格率跌至 36-50%），2025-Q2 后强势恢复至 85-90%

## 四、结论与管理建议

### 4.1 分级评估

| 等级 | 产品 | 基线合格率 | 趋势 | 建议动作 |
|------|------|------------|------|----------|
| 🟢 优秀 | GB6 | 98.25% | 近期下行 | 调查 2026-05 骤降根因，防止形成趋势 |
| 🟡 良好 | 缸体 | 89.71% | 明显下行 | **紧急**：2026 年合格率从 91%→79% 连续下滑，立即排查 Q2 工艺/设备变更 |
| 🟡 良好 | NF1 | 85.37% | 退化中 | 对比 2020 年（95%+）与当前（79%），找出退化根因；关注 2025-01 暴跌是否重演 |
| 🟡 改善中 | 375T | 83.95% | 强势反弹 | 总结 2025-Q2 改善措施，固化为标准作业；监控反弹后是否稳定 |
| 🟠 注意 | EVO | 82.32% | 趋于稳定 | 继续积累数据；解决 37% 记录时间 NULL 的数据采集问题 |
| 🔴 薄弱 | 50T | 76.82% | 长期低位震荡 | **成立专项改善小组**，8 年数据无改善趋势说明现有措施无效 |
| 🔴 薄弱 | GL31 | 75.90% | 数据不可靠 | **先解决数据采集问题**：大量缺月、零样本月，讨论是否保留该产线检测 |

### 4.2 紧急行动项（按优先级）

1. **【本周】缸体合格率下滑调查** — 2026-04~07 连续 4 个月低于 83%（而 2025 同期均在 91%+）。责任人：质量主管，需对比设备编号、模具批次、操作班组。

2. **【本周】GB6 2026-05 暴跌根因分析** — 从 94.69% 骤降至 83.43%，环比降 11.26pp。需调取该月设备日志和原材料批次。

3. **【本月】50T 专项改善立项** — 8 年数据证明自然波动无法提升，需系统性的工艺/设备/人员综合改善方案。目标：3 个月内提升至 85%+。

4. **【本月】GL31 数据治理** — 存在 2013 年遗留数据、大量缺月、零样本月。需确认该产线是否仍在运行，检测系统是否正常采集。

5. **【持续】375T 改善经验复盘** — 2024-Q4 合格率 36-50% → 2025-Q3 恢复至 90%+，这是唯一有明确改善证据的产品线。需总结做了什么，推广至 50T 和 GL31。

## 五、数据局限性

1. **时间格式不一致**：50T/NF1/GL31/EVO 的时间列为字符串（格式 YYYY/MM/DD），需 STR_TO_DATE 转换，可能因格式异常值导致部分记录被归入 NULL 月份。

2. **GL31 数据严重不连续**：2013-2019 期间仅个别月份有数据（2013 年 4 个月，2019 年 8 个月），2020-2023 年间大量缺月。月度趋势对该产品参考价值有限。

3. **EVO 时间 NULL 问题**：56,978 条记录（37%）的时间列为 NULL，无法纳入月度分析，仅参与总体基线计算。需确认数据采集端问题。

4. **缸体 2026-03 异常大月**：单月 466,880 条记录，是正常月份的 10-15 倍。可能为数据批量回灌或产线扩产，该月合格率不宜作为基准参考。

5. **低样本量月份**：部分月度样本 < 100 条，其合格率随机波动大，环比突变信号需结合样本量判断（如 EVO 2025-03 仅 25 条）。

6. **未区分设备和产线**：各表虽有"设备编号"列，但本次分析仅按产品维度汇总。设备级别的差异可能掩盖单台设备的问题。

7. **未关联工序上下文**：密封检测合格率受上游工序（机加工精度、清洗质量）影响，本报告仅反映检测结果，不涉及根因归因。
