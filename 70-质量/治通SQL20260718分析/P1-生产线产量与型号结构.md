# P1-生产线产量与型号结构分析

> 分析日期：2026-07-17 | 数据源：zt_cyl_block_las_mark + zt_dct_las_mark | 数据跨度：2022-11 ~ 2026-07

---

## 一、分析目的

基于缸体激光打标数据（64.6万条），系统分析8条产线的产出能力、型号结构和月度变化趋势，为产能规划、产线分工优化提供数据支撑。同时结合差壳打标数据，评估DCT产品族的增长态势。

---

SELECT device_name AS 产线, COUNT(*) AS 总产量,
       ROUND(COUNT(*)*100.0/(SELECT COUNT(*) FROM zt_cyl_block_las_mark
        WHERE device_name IN ('缸体1线',...,'缸体8线')),1) AS 占比_pct

## 三、② 产品型号结构分布

### SQL

```sql
SELECT DATE_FORMAT(timestamp, '%Y-%m') AS 月份,
  CASE
    WHEN product_type LIKE '%PFI%' THEN 'PFI'
    WHEN product_type LIKE '%MP%' AND product_type LIKE '%NA%' THEN 'MPNA'
    WHEN product_type LIKE '%MP%' THEN 'MP'
    WHEN product_type LIKE '%LPNA%' OR product_type LIKE '%LP_NA%' THEN 'LPNA'
    WHEN product_type LIKE '%LP%' THEN 'LP'
    WHEN product_type LIKE '%TDC%' THEN 'TDC'
    ELSE COALESCE(product_type, 'NULL')
  END AS 产品类型, COUNT(*) AS 产量
FROM zt_cyl_block_las_mark
WHERE device_name IN ('缸体1线',...,'缸体8线') AND timestamp >= '2024-01-01'
GROUP BY 月份, 产品类型 ORDER BY 月份, 产品类型;
```

| 产品类型 | 总产量 | 占比 |
|----------|--------|------|
| LPNA | 172,459 | 26.7% |
| LP | 159,573 | 24.7% |
| MP | 149,332 | 23.2% |
| PFI | 125,629 | 19.5% |
| TDC | 19,441 | 3.0% |
| MPNA | 18,967 | 2.9% |

**型号结构演变总结**：

- **2025年Q4-2026年Q1**：MP需求暴涨（12月20,404件），与PFI形成双主力
- **2026年5月起**：TDC缸体产量爆发（6月11,012件），标志缸体线开始承接差壳类产品

## 四、③ 各产线型号专攻 Pattern

### SQL

```sql
SELECT device_name AS 产线,
  CASE ... END AS 产品类型,
  COUNT(*) AS 产量,
  ROUND(COUNT(*)*100.0/SUM(COUNT(*)) OVER(PARTITION BY device_name), 1) AS 占比_pct
FROM zt_cyl_block_las_mark
WHERE device_name IN ('缸体1线',...,'缸体8线')
GROUP BY 产线, 产品类型
ORDER BY 产线, 产量 DESC;
```

### 各产线型号矩阵

| 产线 | #1主力 | #2 | #3 | 集中度 | 定位特征 |
|------|--------|-----|-----|--------|---------|
| 缸体1线 | LPNA 39.5% | LP 27.7% | PFI 22.4% | 中 | 多面手，三类产品均衡 |
| 缸体2线 | **MP 70.6%** | LPNA 14.8% | PFI 7.1% | **高** | MP专线 |
| 缸体3线 | **MP 74.9%** | LPNA 10.6% | PFI 7.5% | **高** | MP专线 |
| 缸体4线 | LP 42.3% | MP 40.1% | LPNA 10.8% | 中 | LP/MP双主力 |
| 缸体5线 | LPNA 38.4% | PFI 27.5% | LP 19.4% | 中 | LPNA/PFI/LP三足 |
| 缸体6线 | LPNA 42.9% | PFI 33.5% | LP 16.5% | 中 | LPNA+PFI双核 |
| 缸体7线 | MP 44.3% | PFI 35.1% | LP 12.7% | 中 | MP/PFI并重 |
| 缸体8线 | LP 40.2% | **PFI 39.2%** | MP 14.2% | 中 | LP+PFI双核 |

### 专攻度分析

| 专攻度 | 产线 | 特征 |
|--------|------|------|
| **高度专攻** (>70%单型号) | 缸体2线(MP 70.6%), 缸体3线(MP 74.9%) | 两条MP专线，产品切换少 |
| **中度集中** (40-50%单型号) | 缸体1线(LPNA), 缸体4线(LP), 缸体6线(LPNA), 缸体7线(MP) | 有主力型号但需频繁换型 |
| **双核驱动** (两型号合计>70%) | 缸体5线(LPNA+PFI=65.9%), 缸体8线(LP+PFI=79.4%) | 两类产品轮换 |

**管理含义**：
- 缸体2线、3线是**MP缸体专线**，换模频次最低、OEE应最高
- 缸体4线 LP/MP 双主力，占比合计82.4%，换模以两者间切换为主
- 缸体1线、5线、6线型号最分散，**换模损耗应重点关注**

## 五、④ DCT差壳打标产量趋势

### SQL

```sql
SELECT DATE_FORMAT(timestamp, '%Y-%m') AS 月份, COUNT(*) AS 月产量
FROM zt_dct_las_mark WHERE timestamp >= '2024-01-01'
GROUP BY 月份 ORDER BY 月份;
```

### DCT月产量趋势

| 时间段 | 月均产量 | 趋势 |
|--------|---------|------|
| 2024年H1 | ~5,800 | 基线期，仅DCT300 |
| 2024年H2 | ~10,100 | 显著放量 |
| 2025年H1 | ~12,600 | 持续增长 |
| 2025年H2 | ~12,500 | 平稳期 |

| 2026年Q2 | **~28,200** | **爆发式增长** |

### DCT产品结构

| 类型 | 出现时间 | 2026年月均 | 趋势 |
|------|---------|-----------|------|
| DCT300 | 2013年起 | ~14,000 | 主力，DCTECO推出后产量被分流 |

### 缸体打标 vs DCT打标对比

| 月份 | 缸体打标(1~8线) | DCT打标 | 比值 |
|------|---------------|---------|------|
| 2025-12 | 39,170 | 10,060 | 3.9:1 |

**关键发现**：2026年3月起，DCT打标量**超过**缸体打标量。这不是零和关系——缸体打标数据减少可能反映部分缸体产品转移到差壳产线/其他打标系统，或者原缸体线正在转换为DCT产品生产。

## 六、⑤ 产量异常低谷日

### 方法
1. 统计2025年以来每日全厂总产量（1~8线合计），升序排列取最低30天
2. 找出2025年以来完全无任何1~8线打标记录的全厂停产日
3. 计算各产线日均值，筛选日产量<均值30%的异常日

### 全厂停产日（零产出）

| 日期区间 | 天数 | 推断原因 |
|----------|------|---------|
| 2025-01-28 ~ 02-01 | 5天 | 春节假期 |
| 2025-05-06 ~ 05-07 | 2天 | 不明（非节假日） |
| 2026-02-12 ~ 02-22 | **11天** | 春节长假 |
| 2026-04-04 ~ 04-07 | 4天 | 清明节+短期停产 |
| 2026-04-13, 16, 19, 21 | 4天 | 间歇性全厂停产 |
| 2026-05-01 ~ 05-02 | 2天 | 劳动节 |
| 2026-07-05 | 1天 | 不明 |

| 2026-04-18 | 12 | 缸体3线 | 全厂接近停工 |
| 2026-04-23 | 10 | 缸体3线 | 全厂接近停工 |
| 2026-02-23 | 21 | 2,3,4,7线 | 春节后复工首日 |

### ⚠️ 重大异常：2026年4月

**2026年4月是数据记录以来最严重的产能低谷**：
- 4月全月仅产出 **1,727件**（正常月均应为25,000-40,000件）
- 全月仅缸体3线有间断产出，其余7条线几乎完全停产
- 4月有**14天全厂零产出**，10天极低产出（<30件）
- 4月27日起才出现恢复迹象（4线、7线逐步重启）

**可能原因**（需现场确认）：
1. 大规模设备改造/搬迁
2. 订单断档或供应链中断
3. 数据采集系统迁移（打标机未运行或数据未入库）
4. 环保/安全检查导致的强制停产

## 七、结论与建议

### 1. 产能结构：两头分化，新线待稳

- **4-1-5-6 四条老线**贡献了81.4%的累计产量，是产能基盘
- **7-3-2-8 四条新线**（2025年中后陆续投产）合计仅占18.6%，但月均产出在快速爬坡
- **管理行动**：重点关注新线（7/3/2/8）的日均产量是否达到老线水平（目标150件/天）。当前7线日均106件明显偏低，需排查瓶颈。

### 2. 型号格局：从LP独大走向PFI/MP/TDC三极

- 2024年LP系列占绝对主导 → 2025年PFI、MP崛起 → 2026年TDC爆发
- LPNA与LP此消彼长，反映产品代际更替
- **管理行动**：
  - PFI作为增速最快的品类，需评估缸体5/6线的PFI产能是否充足
  - TDC缸体从零到6月11,012件仅用2个月，需确认这是临时转产还是长期产品线调整
  - 若TDC持续放量，建议将1~2条LP线转TDC专用

### 3. 产线专攻策略

- **缸体2线、3线**：维持MP专线定位，减少换模、提升OEE
- **缸体4线**：LP/MP双主力，换模频率高，建议评估SMED改善空间
- **缸体8线**：LP+PFI双核，作为柔性调节线使用
- **管理行动**：缸体1线三类产品均衡（各20-40%），换模损耗最大。建议重新分工——将LPNA集中到1线和6线，PFI集中到5线和8线，LP集中到4线。

### 4. DCT产品爆发与数据联动

- DCT打标量2026年Q2月均28,200件，已超越缸体打标量
- 结合缸体线TDC产品（6月11,012件），DCT产品族（差壳+缸体）月产近40,000件
- **管理行动**：打通 zt_dct_las_mark 与 zt_cyl_block_las_mark 的关联分析，按二维码追溯同一产品的缸体打标→差壳打标→出货全链路

### 5. 产能风险预警

- **2026年4月全面停摆**是最严重预警信号。无论原因是什么，单月损失约25,000件产出，财务影响需评估。
- 建立**日产量<基线50%自动预警**机制（建议cron job），避免再次出现整月停产才被发现的情况。
- 当前2026年7月（半月8,669件）日均仅578件（8线合计），按8线设计产能（日均~1,200件）仅发挥48%。2线已多日无数据（末次6/18），4线产量波动大（日43-173件）。

## 八、数据局限性

1. **打标数据≠实际产量**：激光打标位于特定工序之后，上下游工序的积压/跳过会导致打标数据偏离实际下线产量。例如设备故障时可能跳过打标直接流转。
2. **产线≠物理线**：device_name 反映的是打标工位归属，不同时期同一物理线可能挂载不同 device_name。
3. **product_type 依赖人工录入**：MPNA vs MP 的边界可能因录入习惯而有误差（已知DB_CONTEXT提示"MP/LP_NA混用"）。
4. **DCT打标与缸体打标非同一工序**：两者仅通过时间段对齐做关联，无直接二维码关联（需与 zt_diff_hous_shipment 联表验证）。
5. **2026年4月数据需现场核验**：极低产量可能是打标系统故障/数据未同步而非真实停产，需要现场确认。
6. **缸体9线未纳入**：946条记录，量极小且可能是测试线。
