# Q3：缸体密封失效模式与可修复品流向分析

> 数据源：`zt_cyl_block_seal`（1,137,643 行，2024-08 ~ 2026-07-17）
> 执行日期：2026-07-17

---

## 一、分析目的

1. 识别缸体密封检测的主要失效通道（Pareto）
2. 刻画"可修复"品的时间/产品/通道特征
3. 排查"不合格但出货"的质量风险
4. 对比各产品族的合格率水平

---

## 二、使用的 SQL（全部可复现）

### 2.1 整体结果分布

```sql
SELECT `整体检测结果`, COUNT(*) AS cnt,
  ROUND(COUNT(*)*100.0/(SELECT COUNT(*) FROM `zt_cyl_block_seal`),2) AS pct
FROM `zt_cyl_block_seal`
GROUP BY `整体检测结果`
ORDER BY cnt DESC;
```

### 2.2 失效模式 Pareto — 不合格记录中各通道失效数

```sql
SELECT
  COUNT(*) AS total_不合格,
  SUM(CASE WHEN `箱体检测结果`='不合格' THEN 1 ELSE 0 END) AS 箱体_不合格,
  SUM(CASE WHEN `水道检测结果`='不合格' THEN 1 ELSE 0 END) AS 水道_不合格,
  SUM(CASE WHEN `高压油道检测结果`='不合格' THEN 1 ELSE 0 END) AS 高压油道_不合格,
  SUM(CASE WHEN `螺纹孔检测结果`='不合格' THEN 1 ELSE 0 END) AS 螺纹孔_不合格,
  SUM(CASE WHEN `断刀检测结果`='不合格' THEN 1 ELSE 0 END) AS 断刀_不合格
FROM `zt_cyl_block_seal`
WHERE `整体检测结果`='不合格';
```

### 2.3 多通道同时失效分布

```sql
SELECT
  (CASE WHEN `箱体检测结果`='不合格' THEN 1 ELSE 0 END +
   CASE WHEN `水道检测结果`='不合格' THEN 1 ELSE 0 END +
   CASE WHEN `高压油道检测结果`='不合格' THEN 1 ELSE 0 END +
   CASE WHEN `螺纹孔检测结果`='不合格' THEN 1 ELSE 0 END +
   CASE WHEN `断刀检测结果`='不合格' THEN 1 ELSE 0 END) AS fail_channels,
  COUNT(*) AS cnt
FROM `zt_cyl_block_seal`
WHERE `整体检测结果`='不合格'
GROUP BY fail_channels
ORDER BY fail_channels;
```

### 2.4 可修复品特征

```sql
-- 时间分布
SELECT DATE_FORMAT(`检测时间`, '%Y-%m') AS ym, COUNT(*) AS cnt
FROM `zt_cyl_block_seal`
WHERE `整体检测结果`='可修复'
GROUP BY ym ORDER BY ym;

-- 产品类型分布
SELECT `产品类型`, COUNT(*) AS cnt
FROM `zt_cyl_block_seal`
WHERE `整体检测结果`='可修复'
GROUP BY `产品类型` ORDER BY cnt DESC;

-- 通道分布
SELECT
  COUNT(*) AS total_可修复,
  SUM(CASE WHEN `箱体检测结果`='可修复' THEN 1 ELSE 0 END) AS 箱体_可修复,
  SUM(CASE WHEN `水道检测结果`='可修复' THEN 1 ELSE 0 END) AS 水道_可修复,
  SUM(CASE WHEN `高压油道检测结果`='可修复' THEN 1 ELSE 0 END) AS 高压油道_可修复,
  SUM(CASE WHEN `螺纹孔检测结果`='可修复' THEN 1 ELSE 0 END) AS 螺纹孔_可修复
FROM `zt_cyl_block_seal`
WHERE `整体检测结果`='可修复';
```

### 2.5 是否出货分析

```sql
SELECT `是否出货`, COUNT(*) AS cnt
FROM `zt_cyl_block_seal`
GROUP BY `是否出货`;
```

### 2.6 分产品族合格率对比

```sql
SELECT
  CASE
    WHEN `产品类型` IN ('LPNA','LP_NA','LP','MP/LP_NA') THEN 'LP/LPNA系'
    WHEN `产品类型` IN ('MPNA','MP_NA') THEN 'MPNA系'
    WHEN `产品类型` = 'MP' THEN 'MP'
    WHEN `产品类型` = 'PFI' THEN 'PFI'
    WHEN `产品类型` = 'TDC' THEN 'TDC'
    ELSE `产品类型`
  END AS product_family,
  COUNT(*) AS total,
  ROUND(SUM(CASE WHEN `整体检测结果`='合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 合格率,
  ROUND(SUM(CASE WHEN `整体检测结果`='不合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 不合格率,
  ROUND(SUM(CASE WHEN `整体检测结果`='可修复' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 可修复率
FROM `zt_cyl_block_seal`
WHERE `整体检测结果` IN ('合格','不合格','可修复')
GROUP BY product_family
ORDER BY total DESC;
```

### 2.7 分产品族 x 通道不合格率

```sql
SELECT product_family,
  ROUND(SUM(CASE WHEN `箱体检测结果`='不合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 箱体不合格率,
  ROUND(SUM(CASE WHEN `水道检测结果`='不合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 水道不合格率,
  ROUND(SUM(CASE WHEN `高压油道检测结果`='不合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 高压油道不合格率,
  ROUND(SUM(CASE WHEN `螺纹孔检测结果`='不合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 螺纹孔不合格率,
  ROUND(SUM(CASE WHEN `断刀检测结果`='不合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 断刀不合格率
FROM `zt_cyl_block_seal`
WHERE `产品类型` != '0'
GROUP BY product_family
ORDER BY total DESC;
```

### 2.8 月度合格率趋势

```sql
SELECT DATE_FORMAT(`检测时间`, '%Y-%m') AS ym,
  COUNT(*) AS total,
  ROUND(SUM(CASE WHEN `整体检测结果`='合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 合格率
FROM `zt_cyl_block_seal`
WHERE `整体检测结果` IN ('合格','不合格','可修复')
GROUP BY ym ORDER BY ym;
```

### 2.9 恶化期 vs 基准期通道对比

```sql
SELECT
  CASE WHEN `检测时间` >= '2026-04-01' THEN '恶化期' ELSE '基准期' END AS period,
  COUNT(*) AS total,
  ROUND(SUM(CASE WHEN `整体检测结果`='合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 整体合格率,
  ROUND(SUM(CASE WHEN `箱体检测结果`='不合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 箱体不合格率,
  ROUND(SUM(CASE WHEN `水道检测结果`='不合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 水道不合格率,
  ROUND(SUM(CASE WHEN `高压油道检测结果`='不合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 高压油道不合格率,
  ROUND(SUM(CASE WHEN `螺纹孔检测结果`='不合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 螺纹孔不合格率,
  ROUND(SUM(CASE WHEN `断刀检测结果`='不合格' THEN 1 ELSE 0 END)*100.0/COUNT(*),2) AS 断刀不合格率
FROM `zt_cyl_block_seal`
WHERE `整体检测结果` IN ('合格','不合格','可修复')
GROUP BY period;
```

## 四、结论与管理行动建议

### 4.1 主要失效通道：高压油道 > 水道 > 箱体

**高压油道是第一大失效通道**，贡献了 41.1% 的通道级失效，且恶化期不合格率从 4.50% 翻倍至 10.42%。水道（30.5%）和箱体（21.8%）紧随其后。87% 的不合格为单通道失效，根因定位可行。

→ **行动**：质量部应在 7 月内对高压油道试漏工序进行专项排查——密封面加工精度、密封垫装配、测试参数标定。

### 4.2 近 4 个月出现系统性质量恶化

2026 年 4 月起，整体合格率从历史 ~89% 骤降至 ~78%（-11pp）。恶化并非单一通道导致，而是**箱体（×2.8）、高压油道（×2.3）、螺纹孔（×2.9）、断刀（×7.9）** 四个通道同时恶化，且不限于单一产品族（PFI -12.7pp、MP -7.5pp）。

→ **行动**：排查 2026 年 3-4 月是否有以下变更：
- 新批次原材料/毛坯供应商切换
- 设备大修/参数调整
- 人员换岗或新员工上岗
- 检测设备校准变动
- 工艺变更（切削参数、刀具品牌）

### 4.3 PFI 产品族是当前最大风险

PFI 占总量 49.7%（56.6 万件），恶化期合格率从 90.08% 跌至 77.42%。由于体量最大，PFI 的 12.7pp 下降贡献了不合格增量的绝大部分。

→ **行动**：优先聚焦 PFI 产线的箱体和高压油道工序。

### 4.4 可修复品流向：箱体和高压油道为主

22,863 条可修复记录中，箱体通道（49.2%）和高压油道（36.1%）合计占 85.3%。可修复品高峰出现在 2025-11 至 2026-03，与合格率下降时段重合，暗示该时期的工艺波动同时产生了更多不合格和可修复品。

→ **行动**：建立可修复品返修追溯机制——返修后是否复检合格？返修品二次合格率是多少？

### 4.5 "不合格但出货"风险无法从数据库判定

`是否出货` 字段全表为 NULL，数据库不记录实物是否发出。如需要排查此风险，需通过以下替代途径：

- **ERP/发货系统**：用二维码关联出货记录
- **激光打标表**（zt_cyl_block_las_mark）：打标记录可能间接反映流转状态
- **现场追溯**：抽检近 4 个月不合格品实物去向

### 4.6 LP/LPNA 系和 TDC 的通道级结构性问题

- **LP/LPNA 系**（31.3 万件）：高压油道不合格率 6.96%、水道 4.81%，是全族中这两个通道最高的
- **TDC**（3.0 万件）：高压油道不合格率 19.61%，是其他产品族的 3-5 倍，但恶化期反而在改善（合格率从 56%→74%），且近期产量激增（3,530→26,753）

→ **行动**：TDC 的高压油道工序需要长期工艺攻关，同时确认产量激增原因（新产品导入？）。

## 五、数据局限性

| 局限项 | 说明 |
|--------|------|
| `是否出货` 无数据 | 全表 NULL，无法进行实物流出风险分析 |
| 螺纹孔 73.7% 未检测 | 螺纹孔通道覆盖率仅 26.3%，其缺陷率可能被严重低估 |
| 断刀 81.8% NULL | 断刀检测结果大量缺失，不能判定为"无断刀" |
| 2026-03 数据量异常 | 单月 46.9 万条（月均 ~3.5 万），可能为批量导入或补录，合格率（89.4%）可能不反映当月实际质量水平 |
| 产品类型未归一化 | LPNA/LP_NA/MP/LP_NA 等混写，本次已手动归类，但需 IT 在源头统一编码 |
| 无法区分自动/手动判定 | `整体检测结果` 的来源（自动阈值判定 vs 人工判定）未知 |
| 检测数据列为文本格式 | 通道具体数值（泄漏量 cm³）可进一步解析用于 SPC 分析，本次未涉及 |
