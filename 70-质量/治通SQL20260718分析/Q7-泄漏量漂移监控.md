# Q7 — 缸体密封泄漏量数值提取与漂移监控

> 生成时间: 2026-07-17  |  数据表: zt_cyl_block_seal (113.8万行) + zt_cyl_head_50t_seal (77.3万行)  |  数据跨度: 2024-08 ~ 2026-07

---

## 一、分析目的

密封表检测数据列为文本格式（`02>:  2.04 bar:(OK):  6.55 cm3/`），常规 BI 工具无法直接分析数值趋势。本任务：
1. 用 REGEXP_SUBSTR 提取箱体/水道/高压油道三通道的泄漏量数值(cm3)，生成月度 avg/stddev/P95 趋势
2. 识别合格件泄漏量均值向上漂移的时间段（密封件老化或设备校准失效的前兆信号）
3. 对比合格件 vs 不合格件的泄漏量分布，判定阈值附近临界件的占比
4. 同样方法处理 50T 缸盖水道数据

---

## 二、可复用的SQL提取模板

### 2.1 缸体表通用提取模板

```sql
-- ===== 提取单个通道泄漏量(cm3) =====
-- 替换 `{数据列}` 为: `箱体检测数据` / `水道检测数据` / `高压油道检测数据`
-- 替换 `{结果列}` 为: `箱体检测结果` / `水道检测结果` / `高压油道检测结果`
-- 表: zt_cyl_block_seal  时间: `检测时间`(datetime, 原生)

-- 提取数值(隐式转换, 兼容MySQL locale问题):
0 + REGEXP_SUBSTR(`{数据列}`, '[0-9]+\\.[0-9]+(?= *cm3)')

-- 过滤有效记录:
WHERE `{数据列}` LIKE '%cm3%'

-- 月度统计模板:
SELECT
  DATE_FORMAT(`检测时间`, '%Y-%m') AS ym,
  COUNT(*) AS total_n,
  SUM(CASE WHEN `{数据列}` LIKE '%cm3%' THEN 1 ELSE 0 END) AS valid_n,
  ROUND(AVG(0 + REGEXP_SUBSTR(`{数据列}`, '[0-9]+\\.[0-9]+(?= *cm3)')), 3) AS avg_leak,
  ROUND(STDDEV(0 + REGEXP_SUBSTR(`{数据列}`, '[0-9]+\\.[0-9]+(?= *cm3)')), 3) AS std_leak,
  ROUND(MIN(0 + REGEXP_SUBSTR(`{数据列}`, '[0-9]+\\.[0-9]+(?= *cm3)')), 3) AS min_leak,
  ROUND(MAX(0 + REGEXP_SUBSTR(`{数据列}`, '[0-9]+\\.[0-9]+(?= *cm3)')), 3) AS max_leak
FROM zt_cyl_block_seal
WHERE `{数据列}` LIKE '%cm3%'
GROUP BY ym ORDER BY ym;

-- P95 月度趋势(子查询+PERCENT_RANK):
SELECT ym, ROUND(AVG(leak_val), 3) AS p95_leak
FROM (
  SELECT
    DATE_FORMAT(`检测时间`, '%Y-%m') AS ym,
    0 + REGEXP_SUBSTR(`{数据列}`, '[0-9]+\\.[0-9]+(?= *cm3)') AS leak_val,
    PERCENT_RANK() OVER (
      PARTITION BY DATE_FORMAT(`检测时间`, '%Y-%m')
      ORDER BY 0 + REGEXP_SUBSTR(`{数据列}`, '[0-9]+\\.[0-9]+(?= *cm3)')
    ) AS pct
  FROM zt_cyl_block_seal
  WHERE `{数据列}` LIKE '%cm3%'
) t WHERE pct >= 0.95
GROUP BY ym ORDER BY ym;

-- 按结果分类统计:
SELECT `{结果列}`, COUNT(*) AS n,
  ROUND(AVG(0 + REGEXP_SUBSTR(`{数据列}`, '[0-9]+\\.[0-9]+(?= *cm3)')), 3) AS avg_leak,
  ROUND(STDDEV(0 + REGEXP_SUBSTR(`{数据列}`, '[0-9]+\\.[0-9]+(?= *cm3)')), 3) AS std_leak
FROM zt_cyl_block_seal
WHERE `{数据列}` LIKE '%cm3%'
GROUP BY `{结果列}` ORDER BY n DESC;
```

### 2.2 50T缸盖水道（新旧格式兼容）

```sql
-- 表: zt_cyl_head_50t_seal  时间列: `时间` (char字符串!)
-- ⚠️ 必须 STR_TO_DATE(`时间`, '%Y/%m/%d %H:%i:%s')

-- 旧格式(2018~2024-01): ml/min
0 + REGEXP_SUBSTR(`水道数据`, '-?[0-9]+\\.[0-9]+(?= *ml/min)')

-- 新格式(2024-10起): cm3/mn (注意是 mn 不是 min!)
0 + REGEXP_SUBSTR(`水道数据`, '-?[0-9]+\\.[0-9]+(?= *cm3/mn)')

-- 统一提取(兼容新旧):
WHERE `水道数据` REGEXP '(ml/min|cm3/mn)'
```

### 2.3 关键注意事项

| 陷阱 | 说明 |
|------|------|
| CAST(DECIMAL) 截断 | MySQL 8.0 Windows locale 下 CAST('6.55' AS DECIMAL) 返回 6.000，用 `0 + str` 隐式转换 |
| 50T 时间列是字符串 | 格式 `2025/11/27 14:00:41`，必须 STR_TO_DATE |
| 负值存在 | 水道/50T 数据中负值表示压差测量(低于基准)，是正常合格件，不可过滤 |
| 异常文本 | 不合格记录可能含 'PRESSURE LOW' / 'LARGE LEAK TEST' 而无数值，需 LIKE '%cm3%' 过滤 |
| 停产期 | 50T 2024-02~2024-09 无数据，不是查询错误 |

## 四、漂移识别（Task ②）

### 4.1 高压油道 — 最显著漂移信号 ⚠️

合格件月均泄漏量从 2025-09 的 **0.800 cm3** 逐月攀升至 2026-04 的 **1.509 cm3**，增幅 **+88.6%**。2026-06 起回落至 1.194，2026-07 继续回落至 1.021。

**漂移时间段**: 2025-11 ~ 2026-05（连续7个月高于基线）

**基线**: 2024-08 ~ 2025-09 合格件月均 0.80~1.25（除去 2025-01 的 1.387 异常月）

| 指标 | 基线期均值 | 漂移期峰值 | 变化幅度 |
|------|-----------|-----------|---------|
| 合格件 avg | ~1.03 | 1.509 (2026-04) | +47% |
| 整体 avg | ~1.42 | 2.908 (2026-05) | +105% |
| P95 | ~6.0 | 25.0 (2026-05) | +317% |
| 不合格率 | ~2.5% | 16.4% (2026-07) | +556% |

**判定**: 2026-04/05 为漂移顶点，2026-06 起出现恢复（合格avg 回落到 1.194），但 2026-07 不合格率仍高达 16.4%——可能已经做了校准/维护，但不合格率恢复滞后于均值恢复。

### 4.2 水道 — 2026-04 单月尖峰

合格件月均从 ~0.55~0.85 的范围突然跳升到 2026-04 的 **1.294 cm3** (+105%)，但 2026-05 恢复到 0.723。这是单点尖峰而非持续漂移，可能原因：设备临时故障或特定批次问题。

### 4.3 箱体 — 信号被噪声淹没

箱体泄漏量受不合格件的极端值（1000+ cm3）强烈影响，均值波动大。合格件均值从 2025 年低点 ~5.3 上升到 2026-04 的 10.586，但 2026-06 回落到 6.513。此通道的数据信噪比不足以可靠判定漂移。

## 七、结论与管理行动

### 7.1 核心结论

1. **高压油道存在明确漂移，已部分恢复**: 2025-11~2026-05 连续7个月合格件泄漏量均值从 1.10 升至 1.51 cm3 (+37%)。2026-06 起回落至 1.19~1.02，表明可能已做过校准或维护。但不合格率从 3% 飙升至 16.4% 且尚未回落——**产品质量恢复滞后于均值恢复**。

2. **水道 2026-04 尖峰需回溯**: 单月合格均值翻倍(0.55→1.29)，虽已恢复，需排查该月是否发生了设备异常或特定批次问题。

3. **临界件占比高，监控盲区大**: 高压油道 5.5 万件合格品处于 2~5 cm3 临界区(占合格件 11%)，此区间不合格件占比 45.7%。当前只看"合格/不合格"标签会漏掉这部分渐进劣化信号。

4. **50T 缸盖与缸体可能存在关联**: 50T 水道 2025-09/2025-11 两个不合格高峰与缸体高压油道漂移起始时间(2025-11)重叠，建议检查共享供气/校准系统。

## 八、数据局限性

| 限制 | 影响 | 缓解措施 |
|------|------|---------|
| 检测数据列可能含异常文本 | 不合格记录如 'PRESSURE LOW' / 'LARGE LEAK TEST' 无 cm3 数值，被 WHERE LIKE 过滤排除 | 本报告分别统计 valid_n / total_n，缺失率可追溯 |
| 箱体泄漏量极值严重拉偏均值 | max 达 1897 cm3，极度右偏，avg 可靠性降低 | 已同时报告合格件 avg 和 P95，排除不合格件干扰 |
| 50T 2024-02~2024-09 无数据 | 无法分析这段期间的漂移趋势 | 已标注停产期，非数据缺失 |
| 50T 新旧格式单位不同 | 2018~2024-01 的 ml/min 与 2024-10 起的 cm3/mn 不可直接比较 | 本报告仅分析新格式期，旧格式见原始数据 |
| 泄漏值不是唯一判定因素 | 合格/不合格还取决于压力值、压降曲线等，同一 cm3 值可能合格也可能不合格 | 本报告按结果标签分组分析，临界区代表"数值上接近但不等于超限" |
