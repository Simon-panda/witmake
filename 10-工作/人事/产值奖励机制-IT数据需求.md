# 产值奖励机制 — IT数据对接需求

> 背景：公司拟推行《产值奖励细则（班长专项）》，月产值≥500万元时触发，提取0.7%（~35,000元）奖励生产/质量/工程/物流部班长。
>
> 奖励落地需要将企业云上散落的数据打通，关联到每个班长个人。

---

## 一、需要从企业云提取的数据清单

### 数据1：班组长名册

| 项 | 说明 |
|---|------|
| **来源系统** | 企业微信通讯录 / HR系统 / 花名册 |
| **数据字段** | 姓名、部门、岗位（班长/副班长）、所属产线/班组、管理人数、管理设备数、入职日期、任职班长日期、汇报上级 |
| **用途** | 确定奖励对象范围，按部门分配占比，按管理复杂度加权 |
| **输出格式** | 结构化数据（Excel或DB表） |
| **更新频率** | 月度（发生人员变动时） |

### 数据2：各班组产值数据

| 项 | 说明 |
|---|------|
| **来源系统** | 财务核算系统 / MES系统 |
| **数据字段** | 月份、班组/产线、实际产量、计划产量、产值（元） |
| **用途** | 触发条件判定（公司总产值≥500万），各班组产值贡献评估 |
| **关键** | 需要按**班组维度**而非产品维度统计 |

### 数据3：质量事故记录

| 项 | 说明 |
|---|------|
| **来源系统** | 质量部记录 / 企业微信审批 / 质量管理系统 |
| **数据字段** | 日期、产线/班组、事故类型（批量工废/客户端投诉/设备引发质量事故）、工废数量、责任判定、处理结果 |
| **用途** | 否决条件判定——单次工废≥10件、客户投诉/退货、重大质量事故 |
| **筛选条件** | 必须能关联到具体的班长/班组 |

### 数据4：安全事故与设备违规记录

| 项 | 说明 |
|---|------|
| **来源系统** | 安全员记录 / 设备报修记录 / 企微审批 |
| **数据字段** | 日期、班组、事故类型（工伤/设备安全/违规操作）、停机时长、处理结果 |
| **用途** | 否决条件判定——安全事故取消奖励、违规操作停机>2h扣30% |
| **筛选条件** | 按班组维度汇总，月度统计 |

### 数据5：日报提交与质量数据

| 项 | 说明 |
|---|------|
| **来源系统** | 企业微信汇报（日报模板） |
| **已有数据** | 日报已由 woker 归档到 Obsidian（模板ID: Bs5NH2CSVjBhoNTqmZaR1a5n32dQbz6jx6Ye6BtSZ） |
| **需要新增** | 日报提交率（出勤日提交天数/应提交天数）、日报评分（按5维模型） |
| **用途** | 作为定性评估的参考维度，可纳入加分项 |

### 数据6：历史奖罚记录

| 项 | 说明 |
|---|------|
| **来源系统** | HR记录 / 绩效管理系统 / 企微审批 |
| **数据字段** | 日期、员工、奖惩类型、事由、金额/处分等级 |
| **用途** | 累计奖罚记录可作为奖励分配的参考系数 |
| **时间范围** | 至少从2026年1月起 |

## 二、数据关联逻辑

每月的奖励核算需要将以上数据关联到每个班长：

```
班长名单（数据1）
  ├── 关联 → 当月产值（数据2）→ 是否触发奖励
  ├── 关联 → 质量事故（数据3）→ 是否有否决/扣减
  ├── 关联 → 安全事故/违规（数据4）→ 是否有否决/扣减
  ├── 关联 → 日报数据（数据5）→ 评估管理积极性
  └── 关联 → 历史奖罚（数据6）→ 综合评估
```

## 三、IT交付物建议

### 阶段一：基础数据台账（MVP，1-2周）

由IT协助人事部从企业云导出以下文件（Excel格式）：

| # | 文件名 | 数据源 | 说明 |
|:-:|:-------|:-------|:-----|
| 1 | `班组长名册.xlsx` | 通讯录/HR系统 | 所有班长基本信息 |
| 2 | `月度产值统计.xlsx` | 财务系统 | 按班组维度，每月更新 |
| 3 | `质量事故记录.xlsx` | 质量部记录 | 按班组维度，每月更新 |
| 4 | `安全事故违规记录.xlsx` | 安全员/设备报修 | 按班组维度，每月更新 |
| 5 | `日报提交统计.xlsx` | 企微汇报API | 每人每月提交天数和内容 |
| 6 | `奖罚记录.xlsx` | HR系统 | 全员奖罚历史（至少2026年度） |

### 阶段二：数据自动化（可后续规划）

| 功能 | 说明 |
|:-----|:------|
| 月度自动汇总 | 每月5日前自动从各系统拉取数据 |
| 奖励核算模块 | 输入阈值 → 自动判定否决条件 → 输出应发金额 |
| 签呈生成 | 自动生成《产值奖励签呈》，推送给总经理审批 |
