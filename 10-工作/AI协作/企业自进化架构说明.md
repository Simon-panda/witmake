## 进化层详解

### L1: 反馈日志 → 每一天都在学

每个 cron 任务运行后，自动记录结构化反馈：

```jsonl
{"task":"早间简报","timestamp":"2026-05-07T08:00:00","quality":0.8,
 "issues":["缺少3号线数据"],"improvements":["需要MES API接入"],
 "data_available":false}
```

**指标追踪**：
| 指标 | 含义 | 目标趋势 |
|------|------|----------|
| `quality` | 输出有用性 0-1 | ↗ 持续上升 |
| `completeness` | 数据覆盖率 | ↗ 接近 1.0 |
| `actionability` | 可操作性建议数 | ↗ 持续上升 |
| `latency` | 生成耗时 | ↘ 持续下降 |

### L2: DSPy 优化 → 每周自动进步

**优化目标**：
- 早间简报：提高异常识别准确率
- OEE周报：提高瓶颈归因准确性
- 设备巡检：降低误报率
- 行业雷达：提高信息相关性

**优化命令**（DSPy MIPROv2）：
```bash
python3.11 -m evolution.skills.evolve_skill \
  --skill enterprise-morning-briefing \
  --iterations 10 \
  --optimizer-model deepseek/deepseek-chat \
  --eval-source synthetic \
  --feedback-path workspace/hermes-enterprise/feedback/
```

### L3: 知识蒸馏 → gbrain 知识图谱

从每日交互中提取结构化知识：
- 设备故障模式 → 关联到 equipment-management 页面
- 质量问题溯源 → 关联到 quality-management 页面  
- 成本异常 → 关联到 supply-chain-cost 页面
- 行业洞察 → 新建 technology-intelligence 页面

### L4: Skill 自动更新

DSPy 优化后的 prompt 自动回写到技能文件：
```
workspace/hermes-enterprise/skills/
├── morning-briefing/SKILL.md    (v1 → v2 → v3 ...)
├── oee-weekly/SKILL.md
├── equipment-patrol/SKILL.md
└── industry-radar/SKILL.md
```

## 安全护栏

| 规则 | 说明 |
|------|------|
| 🔒 优化不自动部署 | DSPy 结果先存 `_candidate`，等 Simon 审核 |
| 📊 进化透明 | 每次优化生成 diff 报告，标明改了什么 |
| ↩️ 一键回滚 | `hermes skills revert <name>` 回退到上一版本 |
| 🎯 指标驱动 | 只优化量化指标，不做"我觉得更好"式改动 |
| ⚠️ 退化告警 | 如果新版本指标下降 → 自动暂停 + 告警 |
