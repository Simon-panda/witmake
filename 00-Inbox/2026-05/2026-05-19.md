## 产品体系

### 软件平台（SIS四大平台）

| 平台 | 功能 |
|------|------|
| **WizVision** | AI开发平台：样本生成、智能标记、目标/异常/旋转框检测、图像分割 |
| **WizFlow** | 算法流程平台：经典视觉+AI混合开发，I/O逻辑编程，自动搜参 |
| **WizCloud** | 算力集群平台：自研训练平台，支持各类深度学习框架，无感化算力调用 |
| **WizUI** | 界面组态平台：报表/文本/图片/图表/窗口/按钮组件 |

### 硬件产品线

| 系列 | 功能 | 特点 |
|------|------|------|
| **MEC** | 表面外观成像模组 | 通用设计，灵活部署 |
| **MHS** | 显微外观成像模组 | 高分辨率微观检测 |
| **PCHI** | 360°外观成像模组 | 超高分辨率、高速传输、物距像距可调 |
| **PCPW** | 多面360°外观成像模组 | 大产品多角度检测 |
| **SIZE-T/SIZE-L** | 尺寸检测成像模组 | 500W像素，0.003mm重复精度 |
| **SIC** | 模组控制器 | 高频触发，USB实时通讯 |
| **SLC** | 光源控制器 | 高性能硬件，SIS深度适配 |
| **SIOM** | 数据模块 | PLC连接、多相机触发、综合结果输出 |
| **AVI** | 视觉控制器 | Core i5/i7，DDR5，7×24h连续作业 |
| **EXT** | 扩展模块 | 独立/组合使用 |
| **Tri5990K-Cloud** | AI视觉分选系统 | 多工位，<400pcs/min，可换型 |
| **TVI5120A-Cloud** | AI视觉分选系统 | 模块化灵活部署 |
