# Hermes 安装指南

## 下载

从 GitHub Releases 下载对应系统的安装包：

| 系统 | 安装包格式 | 备注 |
|------|-----------|------|
| macOS | .dmg | 需解除限制 |
| Windows | .exe | 首次运行需信任 |
| Linux | AppImage / deb / rpm | 按发行版选择 |

## 安装后注意事项

### Windows
- 首次运行需点击 **"更多信息"** → **"仍要运行"**

### macOS
- 终端执行解除限制：
  ```bash
  xattr -cr "/Applications/Hermes*"
  ```

### 配置
- 安装后自动引导配置流程
