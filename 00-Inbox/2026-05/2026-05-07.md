## 🖥️ Hermes Web 界面总览

### 两个 Web 界面对比

| | 内置 Dashboard | hermes-webui |
|------|-----------|-------------|
| 地址 | `http://localhost:9119` | `http://localhost:8787` |
| 框架 | FastAPI + xterm.js PTY | Python stdlib + pyyaml |
| 功能 | 嵌入式 TUI 聊天 | 三面板：token监控 / 会话管理 / 配置 |
| 依赖 | 重（需编译 web/ 前端） | 轻（只需 pyyaml） |
| 安装 | Hermes 自带 | `git clone nesquena/hermes-webui` |

### 一键启动脚本

```bash
bash ~/.hermes/scripts/hermes-start.sh
```

自动检测两个服务是否已运行，未运行则启动。

### 单独启动

```bash
# Dashboard（嵌入式 TUI 聊天）
hermes dashboard --tui --no-open &

# hermes-webui（token 监控 + 会话管理）
cd ~/hermes-webui && HERMES_WEBUI_PYTHON=/opt/homebrew/bin/python3.11 bash start.sh 8787 &
```

### 更新后 Dashboard 自动重启

```bash
bash ~/.hermes/scripts/hermes-update.sh
```

封装了 `hermes update` + 自动 kill 旧 Dashboard + 重启。

### 相关技能

- `hermes-ecosystem-tools` — 包含 hermes-webui、gbrain（知识图谱）、self-evolution（DSPy优化）
- `hermes-update-restart` — 更新后自动重启 Dashboard 的工作流
- `web-search-plus` — 10 提供商智能路由搜索（已安装，待配 API Key）

## 📋 高新技术企业新规解读（2026年即将实施）

### 一、新规背景与影响
- 自2016年以来最大调整，影响新申请企业和需重新复核的企业
- 被称为"史上最严认定改革"，目的：淘汰虚假包装企业，支持有创新实力的公司

### 二、知识产权要求
- **软著**：严格筛查，驳回模板化软著
- **专利**：受让或外购专利需出具产业化应用证明，证明专利用于生产并产生实际产业价值才被认可

### 三、人员标准
- 科技人员需在企业累计工作满183天
- 通过社保、劳动合同和工时记录三项验证
- 兼职岗位不算在内

### 四、研发费用核算监管
- 财务账、申报账、税务账必须一致，数据差异不超过5%
- 非研发支出、日常运维和普通技术改造不能混入研发费用
- 每笔研发费用需真实可查

### 五、审核模式与技术领域调整
- 采用实地核查和穿透式监管，对研发场地、设备、人员和活动现场查验
- 年度抽查比例提高，动态监管，造假即取消资格
- **技术领域**：移除12个成熟技术和传统产业，新增6个前沿领域，企业技术和主营领域须匹配

### 六、违规惩罚措施
- **企业惩罚**：造假企业取消高企资质，追回已享受优惠，影响招投标和融资资格
- **中介追责**：帮企业包装的中介机构追究连带责任
- **资质撤销**：已获高企资质但后续不达标，撤销资质并追回已享受优惠

### 七、企业应对布局
1. **知识产权**：停止突击买专利和批量申请软著，培育自主核心知识产权
2. **人员管理**：规范研发人员管理，对应好社保、合同和工时记录
3. **研发费用**：做好研发费用辅助账，确保三表一致
4. **成果转化**：留存成果转化、高新收入的合同和发票
