# 飞书多维表格 - 员工调薪申请系统快速上手指南

## 一、系统创建步骤

### 步骤1：创建多维表格
1. 打开飞书，进入"工作台"
2. 点击"创建" → "多维表格"
3. 选择"从空白创建"
4. 输入应用名称：`员工调薪申请管理系统`
5. 选择图标和颜色主题
6. 点击"创建"

### 步骤2：创建基础表格

#### 表1：员工基本信息表
1. 点击"新建数据表" → "新建空白表格"
2. 表名：`员工基本信息表`
3. 添加以下字段：

| 字段名称 | 字段类型 | 配置说明 |
|----------|----------|----------|
| 员工ID | 文本 | 必填，唯一标识 |
| 姓名 | 文本 | 必填 |
| 部门 | 单选 | 选项：质保部、生产部、技术部、行政部、财务部 |
| 职位 | 文本 | 必填 |
| 入职日期 | 日期 | 格式：YYYY.MM.DD |
| 基本薪资 | 数字 | 单位：元，小数位数：0 |
| 绩效基数 | 数字 | 单位：元，小数位数：0 |
| 加班费标准 | 数字 | 单位：元/小时，小数位数：2 |
| 在职状态 | 单选 | 选项：在职、离职、休假 |
| 创建时间 | 创建时间 | 自动 |
| 更新时间 | 修改时间 | 自动 |

#### 表2：调薪申请记录表
1. 点击"新建数据表" → "新建空白表格"
2. 表名：`调薪申请记录表`
3. 添加以下字段：

| 字段名称 | 字段类型 | 配置说明 |
|----------|----------|----------|
| 申请ID | 文本 | 公式：="SA"&TEXT(TODAY(),"YYYYMMDD")&"-"&TEXT(ROW(),"000") |
| 员工 | 单向关联 | 关联表：员工基本信息表，显示字段：姓名 |
| 申请日期 | 日期 | 默认值：今天 |
| 生效日期 | 日期 | 必填 |
| 调薪类型 | 单选 | 选项：绩效调整、职位调整、综合调整 |
| 调整前职位 | 文本 | 自动从员工表带出 |
| 调整后职位 | 文本 | 必填 |
| 调整前薪资 | 数字 | 自动从员工表带出 |
| 调整后薪资 | 数字 | 必填，单位：元 |
| 调薪金额 | 公式 | =调整后薪资-调整前薪资 |
| 调薪比例 | 公式 | =IF(调整前薪资>0, 调薪金额/调整前薪资, 0) |
| 申请理由 | 多行文本 | 必填 |
| 员工表现 | 多行文本 | 必填 |
| 审批状态 | 单选 | 选项：待审批、部门审批中、总经理审批中、已批准、已驳回 |
| 审批人 | 人员 | 选择审批人 |
| 审批日期 | 日期 | 自动 |
| 审批意见 | 多行文本 | |
| 创建人 | 创建人 | 自动 |
| 创建时间 | 创建时间 | 自动 |

## 二、自动化配置

### 1. 审批流程自动化
1. 进入"自动化" → "新建自动化"
2. 触发器：当"调薪申请记录表"新增记录时
3. 动作1：发送飞书消息给部门经理
   - 消息模板：`新的调薪申请待审批 - {员工姓名}`
4. 动作2：更新记录状态为"部门审批中"
5. 保存并启用

### 2. 数据同步自动化
1. 新建自动化
2. 触发器：当"调薪申请记录表"中"审批状态"变为"已批准"
3. 动作：更新"员工基本信息表"中的薪资数据
   - 匹配条件：员工ID相同
   - 更新字段：基本薪资、绩效基数、职位
4. 保存并启用

### 3. 提醒通知自动化
1. 新建自动化
2. 触发器：每天上午9点
3. 动作：发送待审批申请提醒
   - 筛选条件：审批状态="部门审批中"且申请日期>3天前
   - 发送给：对应审批人
4. 保存并启用

## 三、视图配置

### 1. 待审批申请视图
1. 在"调薪申请记录表"点击"新建视图"
2. 视图名称：`待审批申请`
3. 筛选条件：审批状态 包含 待审批,部门审批中,总经理审批中
4. 排序：申请日期 升序
5. 分组：按部门分组
6. 保存

### 2. 部门薪资统计视图
1. 在"员工基本信息表"点击"新建视图"
2. 视图名称：`部门薪资统计`
3. 分组：按部门分组
4. 显示字段：员工数量、平均薪资、最高薪资、最低薪资
5. 保存

### 3. 员工历史记录视图
1. 在"调薪申请记录表"点击"新建视图"
2. 视图名称：`员工薪资历史`
3. 筛选条件：选择特定员工
4. 排序：生效日期 降序
5. 保存

## 四、权限配置

### 1. 员工权限
1. 进入"权限管理"
2. 添加权限组："员工组"
3. 数据权限：
   - 员工基本信息表：仅查看自己的记录
   - 调薪申请记录表：可新建、查看自己的记录
4. 操作权限：提交申请、查看审批进度

### 2. 经理权限
1. 添加权限组："经理组"
2. 数据权限：
   - 员工基本信息表：查看本部门记录
   - 调薪申请记录表：查看本部门申请，可审批
3. 操作权限：审批申请、查看部门统计

### 3. 管理员权限
1. 添加权限组："管理员组"
2. 数据权限：全部数据
3. 操作权限：全部操作

## 五、数据导入

### 1. 准备导入文件
1. 使用Excel准备CSV文件
2. 文件格式：UTF-8编码
3. 列顺序与表格字段一致
4. 数据清洗：去除空行、统一格式

### 2. 执行导入
1. 在表格页面点击"导入"
2. 选择"从CSV文件导入"
3. 上传文件
4. 映射字段对应关系
5. 执行导入
6. 验证导入结果

### 3. 导入陈永灯示例数据
```csv
员工ID,姓名,部门,职位,入职日期,基本薪资,绩效基数,加班费标准,在职状态
CY20230402,陈永灯,质保部,外检（来料检）,2023.4.2,2740,500,按公司规定,在职
```

## 六、使用流程

### 员工提交申请
1. 登录飞书，进入"员工调薪申请管理系统"
2. 点击"调薪申请记录表"
3. 点击"新建记录"
4. 填写申请信息：
   - 选择员工（自动带出当前用户）
   - 填写生效日期
   - 选择调薪类型
   - 填写调整后职位和薪资
   - 详细说明申请理由和员工表现
5. 点击"提交"

### 经理审批
1. 收到飞书通知
2. 点击通知进入申请详情
3. 查看申请信息
4. 点击"审批"按钮
5. 选择"通过"或"驳回"
6. 填写审批意见
7. 点击"确认"

### 总经理审批
1. 部门经理审批通过后自动流转
2. 收到飞书通知
3. 查看申请详情
4. 做出最终审批决定
5. 填写审批意见
6. 点击"确认"

### HR处理
1. 申请批准后自动通知HR
2. HR确认薪资更新
3. 系统自动更新员工信息
4. 发送通知给员工

## 七、常见问题解决

### Q1：如何修改已提交的申请？
A：在审批前，创建人可以修改自己的申请。审批开始后需要联系审批人撤回。

### Q2：审批流程卡住了怎么办？
A：检查审批人是否已处理，或联系系统管理员检查自动化配置。

### Q3：数据导入失败？
A：检查CSV文件格式、编码和字段映射，确保数据格式正确。

### Q4：权限设置错误？
A：联系系统管理员调整权限配置。
