# 飞书多维表格创建 - 详细步骤指南

## 第一步：登录飞书并进入工作台

1. 打开飞书网页版：https://www.feishu.cn
2. 使用公司账号登录
3. 点击左侧菜单栏的"工作台"

![工作台位置](https://sf3-cn.feishucdn.com/obj/eden-cn/ljhwzqkjuhp/工作台位置.png)

## 第二步：创建多维表格应用

1. 在工作台页面，点击右上角的"创建"按钮
2. 在弹出的菜单中选择"多维表格"
3. 输入应用名称：`员工调薪申请管理系统`
4. 选择应用图标（建议选择人力资源相关图标）
5. 点击"创建"按钮

![创建多维表格](https://sf3-cn.feishucdn.com/obj/eden-cn/ljhwzqkjuhp/创建多维表格.png)

## 第三步：创建员工基本信息表

### 3.1 新建表格
1. 在新建的多维表格应用中，点击"新建数据表"
2. 选择"新建空白表格"
3. 输入表名：`员工基本信息表`

### 3.2 添加字段
按照以下顺序添加字段：

| 序号 | 字段名称 | 字段类型 | 配置说明 |
|------|----------|----------|----------|
| 1 | 员工ID | 文本 | 必填，唯一标识 |
| 2 | 姓名 | 文本 | 必填 |
| 3 | 部门 | 单选 | 点击"编辑选项"，添加：质保部、生产部、技术部、行政部、财务部 |
| 4 | 职位 | 文本 | 必填 |
| 5 | 入职日期 | 日期 | 格式选择"YYYY.MM.DD" |
| 6 | 基本薪资 | 数字 | 单位选择"元"，小数位数：0 |
| 7 | 绩效基数 | 数字 | 单位选择"元"，小数位数：0 |
| 8 | 加班费标准 | 文本 | 描述性字段 |
| 9 | 在职状态 | 单选 | 选项：在职、离职、休假 |
| 10 | 创建时间 | 创建时间 | 自动生成，无需配置 |
| 11 | 更新时间 | 修改时间 | 自动生成，无需配置 |

### 3.3 配置字段属性
1. 对于"员工ID"字段，点击字段右侧的"..."菜单
2. 选择"字段属性"
3. 勾选"必填"选项
4. 同样为"姓名"、"部门"、"职位"设置必填

## 第四步：创建调薪申请记录表

### 4.1 新建表格
1. 再次点击"新建数据表"
2. 选择"新建空白表格"
3. 输入表名：`调薪申请记录表`

### 4.2 添加字段
按照以下顺序添加字段：

| 序号 | 字段名称 | 字段类型 | 配置说明 |
|------|----------|----------|----------|
| 1 | 申请ID | 文本 | 公式：`="SA"&TEXT(TODAY(),"YYYYMMDD")&"-"&TEXT(ROW(),"000")` |
| 2 | 员工 | 单向关联 | 关联表选择"员工基本信息表"，显示字段选择"姓名" |
| 3 | 申请日期 | 日期 | 默认值选择"今天" |
| 4 | 生效日期 | 日期 | 必填字段 |
| 5 | 调薪类型 | 单选 | 选项：绩效调整、职位调整、综合调整 |
| 6 | 调整前职位 | 文本 | 从关联字段自动带出 |
| 7 | 调整后职位 | 文本 | 必填字段 |
| 8 | 调整前薪资 | 数字 | 从关联字段自动带出 |
| 9 | 调整后薪资 | 数字 | 必填，单位：元 |
| 10 | 调薪金额 | 公式 | 公式：`=调整后薪资-调整前薪资` |
| 11 | 调薪比例 | 公式 | 公式：`=IF(调整前薪资>0, 调薪金额/调整前薪资, 0)` |
| 12 | 申请理由 | 多行文本 | 必填字段 |
| 13 | 员工表现 | 多行文本 | 必填字段 |
| 14 | 审批状态 | 单选 | 选项：待审批、部门审批中、总经理审批中、已批准、已驳回 |
| 15 | 审批人 | 人员 | 选择飞书用户 |
| 16 | 审批日期 | 日期 | 自动记录 |
| 17 | 审批意见 | 多行文本 | |
| 18 | 创建人 | 创建人 | 自动生成 |
| 19 | 创建时间 | 创建时间 | 自动生成 |

### 4.3 配置公式字段
1. 点击"申请ID"字段
2. 在右侧属性面板选择"公式"
3. 粘贴公式：`="SA"&TEXT(TODAY(),"YYYYMMDD")&"-"&TEXT(ROW(),"000")`
4. 同样配置"调薪金额"和"调薪比例"字段的公式

## 第六步：创建视图

### 6.1 待审批申请视图
1. 在"调薪申请记录表"点击"新建视图"
2. 视图名称：`待审批申请`
3. 筛选条件：`审批状态 包含 待审批,部门审批中,总经理审批中`
4. 排序：`申请日期 升序`
5. 分组：`按部门分组`
6. 点击"保存"

### 6.2 员工薪资历史视图
1. 再次点击"新建视图"
2. 视图名称：`员工薪资历史`
3. 筛选条件：选择特定员工
4. 排序：`生效日期 降序`
5. 点击"保存"

## 第七步：配置权限

### 7.1 创建权限组
1. 点击右上角的"权限管理"
2. 点击"新建权限组"
3. 组名：`员工组`
4. 数据权限：
   - 员工基本信息表：仅查看自己的记录
   - 调薪申请记录表：可新建、查看自己的记录
5. 点击"保存"

### 7.2 添加用户
1. 在权限组列表中找到"员工组"
2. 点击"添加成员"
3. 选择需要添加的员工
4. 同样创建"经理组"和"管理员组"

## 常见问题解决

### Q1：导入CSV文件失败
**解决方案：**
1. 检查CSV文件编码是否为UTF-8
2. 检查字段分隔符是否为逗号
3. 检查数据格式是否正确

### Q2：公式字段不计算
**解决方案：**
1. 检查公式语法是否正确
2. 确保引用的字段存在且类型正确
3. 刷新页面或重新保存记录

### Q3：权限设置无效
**解决方案：**
1. 检查用户是否已添加到正确的权限组
2. 检查数据权限设置是否正确
3. 清除浏览器缓存后重新登录

### Q4：关联字段不显示数据
**解决方案：**
1. 检查关联表是否有数据
2. 检查关联字段配置是否正确
3. 重新选择关联关系
