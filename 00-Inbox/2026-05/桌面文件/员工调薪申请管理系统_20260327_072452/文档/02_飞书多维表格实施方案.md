## 2. 自动化工作流设计

### 审批流程自动化
```
触发条件：新建调薪申请记录
→ 自动发送飞书通知给部门经理
→ 部门经理审批（通过/驳回）
→ 自动发送通知给总经理
→ 总经理最终审批
→ 自动更新员工薪资信息
→ 发送通知给HR和员工本人
```

### 数据同步自动化
- 调薪申请批准后，自动更新员工基本信息表中的薪资数据
- 每月自动生成薪资调整报表
- 季度自动生成部门薪资分析报告

## 3. 权限管理设计

### 权限层级
| 角色 | 数据权限 | 操作权限 |
|------|----------|----------|
| 员工 | 查看自己的信息 | 提交调薪申请 |
| 部门经理 | 查看本部门数据 | 审批本部门申请 |
| 总经理 | 查看全公司数据 | 最终审批 |
| HR管理员 | 查看全公司数据 | 数据维护、报表生成 |
| 系统管理员 | 全部数据 | 全部操作 |

## 4. 报表与视图设计

### 标准视图
1. **待审批申请视图** - 按审批状态筛选
2. **已批准申请视图** - 按生效日期排序
3. **部门薪资对比视图** - 部门间薪资对比
4. **员工薪资历史视图** - 单个员工薪资变化趋势

### 自动化报表
1. **月度调薪统计报表** - 每月1日自动生成
2. **年度薪资预算报表** - 每年12月自动生成
3. **部门绩效关联分析** - 季度自动分析
