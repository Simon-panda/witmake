## 🔬 AI 量化交易框架调研 — 2026-06-07

### 一、与 VibeTrading 最相似的 AI 策略生成框架

| 项目 | 核心特点 | 与 VibeTrading 的异同 |
|------|---------|----------------------|
| **OpenClaw** | "Brain + Muscle" 架构，自然语言指令 → 模块化 Skill 执行，支持 Alpaca、Binance 等实盘，Telegram/WhatsApp 控制 | 最像的竞品，生态更大（33.5万+ Stars），Skill 体系更成熟 |

| 项目 | 核心特点 | Stars |

### 三、多 Agent 投研框架

| 项目 | 核心特点 |
|------|---------|
| **TradingAgents** | 多 Agent 辩论机制（基本面/技术/情绪/风控），输出研究报告，不支持实盘 |

### 四、能否安装到 Hermes Agent？

Hermes Agent 核心机制是 Skill 系统（`SKILL.md` 放在 `~/.hermes/skills/` 即可生效），支持 `hermes skills install <github-repo>` 和 `hermes skills install <identifier>` (Skills Hub)。

| 框架 | 可行性 | 方式 | 评估 |
|------|:---:|------|:---:|
| **OpenClaw** | ✅ 最易 | 官方 Skill 格式，社区已有迁移工具，与 Hermes 高度兼容 | ⭐⭐⭐⭐⭐ |
| **VibeTrading** | ✅ 可行 | 封装 CLI 命令和模板逻辑为 `SKILL.md` | ⭐⭐⭐⭐ |
| **TradingAgents** | ✅ 可行 | Python 库形式，写成 Hermes Skill 调用 `TradingAgentsGraph.propagate()` | ⭐⭐⭐ |
| **Freqtrade** | ⚠ 间接 | Hermes 通过 MCP 或 shell 调用其 API/CLI，非原生 Skill | ⭐⭐⭐ |
| **Hummingbot** | ⚠ 间接 | 通过 REST API，Hermes 发 HTTP 请求控制 | ⭐⭐⭐ |
| **Jesse** | ⚠ 间接 | 偏回测研究，可通过 Python import 集成，实盘能力弱 | ⭐⭐ |

### 五、综合推荐

1. **主力**：OpenClaw（或 VibeTrading 封装成 Skill）— 自然语言 → 策略生成 → 实盘执行
2. **回测引擎**：Jesse — 零 look-ahead bias 回测验证策略
3. **投研辅助**：TradingAgents — 封装成"策略评审 Skill"，实盘前多 Agent 交叉审查
4. **后台执行**：Freqtrade（可选）— 成熟 DCA/Grid 策略，通过 cron 定时调用

> ⚠️ 风险提示：所有自动化交易工具都存在亏损风险，实盘前务必经过充分回测，小资金验证。AI 生成的策略可能包含逻辑漏洞，切勿直接投入大额资金。
