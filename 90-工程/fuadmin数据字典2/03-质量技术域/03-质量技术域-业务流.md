# A4 质量技术域 核心业务流

## 1. 刀具全生命周期流
表链路: generator_knife_requisition(领料) → generator_tool_storage(入库) → generator_eng_tool_knives(工程部放刀) → generator_take_tool(领刀) → generator_machine_tool_change(机床换刀) / generator_tool_replacement(换刀片) → generator_tool_return_table(返库) / generator_old_knife_recycle(旧刀回收) → generator_tool_scrap(报废)
关键关联字段: 刀具条码(bar_code/barcode)贯穿全程，柜号(cabinet_id/cabinet_number)定位智能刀具柜。
说明: 刀具从领料采购入库开始，由工程部配放到刀柜，生产领用后上机加工；换刀/换刀片记录新旧刀条码与原因；用后刀具返库或作为旧刀回收，最终报废。generator_knife_detail 为单把刀全生命周期明细账，generator_knife_statistics 合并各环节数据做全链统计。

## 2. 刀具寿命监控流
表链路: generator_knife_life_standards(寿命标准) → generator_machine_tool_change/generator_knife_detail(实际加工量与使用时长) → generator_abnormal_tool_filtering_data(异常推送)
关键关联字段: tool_model + bar_code/barcode + production_line。
说明: 按"刀具型号+产品+产线"设定加工量(std_completed_quatitiy)与使用时长(std_usage_hour)标准值；现场换刀与明细账回写实际数据；监控算法筛出超寿命/异常刀具并推送，is_resolved 跟踪处理闭环。knife_jobcode 提供工作代号到产线的映射匹配。

## 3. 质量检验流
表链路: generator_inspection_standards / generator_inspection_items(标准) → generator_quality_inspection(巡检) → generator_cmm_inspection_log(三坐标送检) → generator_product_szb(三坐标报告) → generator_qualityrapid_response(异常闭环)
关键关联字段: product_name / qr_code(产品二维码) / quality_exception(异常单号)。
说明: 巡检点位(generator_inspection_points)扫码触发巡检记录；首件/抽检产品送三坐标测量，报告落入 product_szb（15万+行数据中心）；发现异常开具质量快速反应单(QRQC)，经原因分析→临时措施→永久措施→标准化完成闭环。

## 4. 设备维保流
表链路: generator_devices(台账) → generator_inspection_standards(点检保养标准, devices.type_id) → generator_equipment_inspection(点检) / generator_equipment_maintenance_records(周期保养) / generator_equipment_repair(报修工单) → generator_maintenance_records(维修执行)
关键关联字段: device_id / inspection_equipment_id / equipment_id → generator_devices.id。
说明: 设备台账挂接点检标准(含月/季/年保养明细)；日常点检与周期保养按标准执行并回写日期；故障走新版报修工单(状态1待接单→6已完成，含紧急等级与评分)；切削液浓度另有 generator_device_cutting_fluid_check 专项巡检，对照 devices.concentration_range。

## 5. 测量计量校准流
表链路: generator_measuring_instrument(器具档案) → generator_calibration_record(检定记录)
关键关联字段: instrument_id → generator_measuring_instrument.id；calibration_cycle_days 驱动 next_date。
说明: 计量器具按(site, number)唯一建档，定义校准周期；每次检定记录结果(result)与检定日期(date)，按周期推算下次检定日期(next_date)，索引支持到期预警。

## 6. 产品赋红预警流
表链路: generator_product(产品主档) → generator_product_urgent_mark(赋红标记) → generator_product_urgent_record(操作流水)
关键关联字段: product_qrcode(产品二维码) + product_name。
说明: 对重点产品按二维码打 1红(致命)/2橙(严重)/3黄(一般)/4蓝(提示) 四级紧急标记，active_state 控制激活，state 跟踪验证；每次赋红/操作写入 urgent_record 流水(操作人、报警内容)供追溯。

## 7. 设备效率分析流
表链路: generator_devices(台账) → generator_devices_log(状态流水) → generator_device_eff(效率分析)
关键关联字段: device_id → generator_devices.id。
说明: 设备状态变更(运行/停机/报警)记入日志；按日汇总运行时长(runtime)、停机时长(downtime)、产量(production_count)算出效率(efficiency)，并以 recommendations 给出改进建议。
