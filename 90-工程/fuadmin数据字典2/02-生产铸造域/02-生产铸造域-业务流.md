# A3 生产铸造域 业务流（规则引擎锚点版，待agent精修替换）

## 1. 铸造生产主链（计划→熔炼→制芯→浇注→检验）
表链路: generator_tf_production_plan（生产计划, batch_status 0=NO/1=OK, mode_clean 0=×/1=√） → generator_tf_furnace_smelt（熔炼, state 1=炉前/2=炉后） → generator_tf_coremaking（制芯, chromatism 色差1-8级） → generator_tf_pouring_records（浇注） → generator_tf_cast_inspection（铸造成品检验）
说明: 生产计划与熔炼/制芯/浇注/检验各工序表通过 M2M 中间表（generator_tf_*_production_plan）多对多关联，一个计划对应多工序记录；熔炼分炉前/炉后两态，制芯按 S2K-* 批次号组织（与生产批次单号 RA5-* 编码规则不同，generator_tf_coremaking_batch_relation 一批次对一单号、一单号对多批次——全库仅有的真实注释锚点）。

## 2. 二维码追溯现役链（登记→发货→复核→换码）
表链路: generator_registration_qrcode（二维码登记） → generator_qrcode_sendout（发货扫码, type 0=错误/1=正常/2=退货/3=隐藏, Manager默认只查0/1/2） → generator_box_code_verify（箱码AI复核） → generator_extraneous（换码记录）
说明: sendout 为交付口径主表（3.9万行）：件数=SUM(number)、箱数=COUNT(DISTINCT box_code)；bar_code 是产品条码非件码；customer_order_id 软外键回链客户订单；part_qr_codes JSON 存箱内零件码，part_qr_verified 标记整箱验证状态。退货按 0HKG 码一物一码。

## 3. 不良→返工→换码闭环
表链路: generator_bad_product（不良品正式单）/ generator_defective_product（工废料废日报, 两套口径勿相加） → generator_rework_record_header + generator_rework_record（返工单头/明细） → generator_extraneous（返修后换码重发）
说明: 不良品两套口径并行：bad_product 走正式单据流，defective_product 走工废/料废日报口径；返工完成后经 extraneous 换码重新进入发货链——追溯与不良两模块唯一实体级闭环。

## 4. 生产计划与排程链
表链路: generator_plan_delivery_plan（交付计划, period_type year=年计划/month=月计划/day=日计划） → generator_newscheduling（新排程） → generator_production_tracking（生产跟踪/报工）
说明: 交付计划按年/月/日三级周期管理；plan_delivery_plan_log 记录 create/update/delete/gen_order 操作；报工 actual_output 为工序级口径，同件多工序重复计数，后段工序（穿扎带/清整/密封）量级≈交付量可交叉验证，外检按件重复计数不可当产量。

## 5. 班次排班链
表链路: generator_shift_template（班次模板, pattern_type fixed_day=固定白班/fixed_night=固定夜班/rotate_2w=双周轮班/custom=自定义） → generator_shift_schedule（排班, shift 白班/夜班/休息）
说明: 模板驱动排班；holiday_date 节假日表参与班次计算。
